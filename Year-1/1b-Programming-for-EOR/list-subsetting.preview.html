Single and Double Brackets¶

Definition¶

For a list l, single and double square brackets return different things:

  • Single brackets l[i] return a list containing the selected elements. Several elements can be selected at once, as in l[c(1, 3)].
  • Double brackets l[[i]] extract one element itself, with its own type: a vector, a matrix, a data frame or another list.
  • For a named list, l$name extracts the element called name; it is the same as l[["name"]].

The same holds for a data frame, which is a list of columns: df["Height"] is a data frame with one column, while df[["Height"]] and df$Height are the column itself, a vector.

Interpretation¶

Think of a list as a train of carriages, each carrying some cargo. l[1] uncouples the first carriage: you still have a (short) train, that is, a list. l[[1]] opens the carriage and hands you the cargo.

The figure shows Example 1. The single-bracket result keeps the outer box (blue): it is a list of length 1 and prints with the label [[1]]. The double-bracket result has no box around it (green): it is the number 1, a numeric vector, and can be used in arithmetic.

The difference matters as soon as the element is used. Functions that expect numbers do not work on a list, even a list of length 1: + and sum() stop with an error, and mean() returns NA with a warning. Single brackets are the right tool when the result should stay a list, for example to keep a few named elements together; double brackets or $ are the right tool for working with one element. Double brackets can be chained to reach inside nested structures: l1[[2]][2] takes the second element of the list and then its second value, using subsetting by position on the vector.

A common mistake is to write l[1] + 1 and get an error about a non-numeric argument, because l[1] is a list. The same confusion appears with data frames: df["Height"] cannot be passed to mean(), but df$Height can.

Key Results¶

  • l[i] returns a list (a sub-list); l[[i]] returns the element itself.
  • [ ] can select several elements; [[ ]] selects exactly one.
  • For named lists, l$name is the same as l[["name"]], and l["name"] is a list of length 1.
  • On a data frame, df[["col"]] and df$col give the column as a vector; df["col"] gives a one-column data frame.
  • Brackets can be chained: l[[i]][j] takes position j inside element i.

Examples¶

1. List or element.

l <- list(1, 2, 3)
l[1]
#> [[1]]
#> [1] 1
#>
l[[1]]
#> [1] 1
class(l[1])
#> [1] "list"
class(l[[1]])
#> [1] "numeric"

2. Named lists.

l <- list(A = 1, B = 2, C = 3)
l$A
#> [1] 1
l[["B"]]
#> [1] 2
l["B"]
#> $B
#> [1] 2
#>
l[c("A", "C")]
#> $A
#> [1] 1
#>
#> $C
#> [1] 3

3. Reaching inside a nested structure.

l1 <- list(A = 'character', B = c(10L, 20L),
           C = matrix(c(FALSE, FALSE, TRUE, FALSE), nrow = 2, ncol = 2))
l1[[2]][2]
#> [1] 20
l1$C[1, 2]
#> [1] TRUE

l1[[2]] is the integer vector 10 20, and [2] then takes its second value; l1$C is the matrix, and [1, 2] its cell in row 1, column 2.

4. Pitfalls: arithmetic on a sub-list.

l <- list(1, 2, 3)
l[1] + 1
#> Error in l[1] + 1 : non-numeric argument to binary operator
l[[1]] + 1
#> [1] 2
df <- data.frame(Name = c('Chip', 'Chap'), Height = c(35, 37))
mean(df[["Height"]])
#> [1] 36
class(df["Height"])
#> [1] "data.frame"

df["Height"] is still a data frame, so it is not a vector of numbers; df[["Height"]] (or df$Height) is.
