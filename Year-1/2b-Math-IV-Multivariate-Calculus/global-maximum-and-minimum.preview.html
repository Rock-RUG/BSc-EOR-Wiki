Global Maximum and Minimum¶

Definition¶

Let A⊆RnA\subseteq\mathbb{R}^nA⊆Rn, let f ⁣:A→Rf\colon A\to\mathbb{R}f:A→R, and let x∗∈Ax^\ast\in Ax∗∈A.

  • f(x∗)f(x^\ast)f(x∗) is a global maximum if f(x∗)≥f(x)f(x^\ast)\ge f(x)f(x∗)≥f(x) for all x∈Ax\in Ax∈A.
  • f(x∗)f(x^\ast)f(x∗) is a global minimum if f(x∗)≤f(x)f(x^\ast)\le f(x)f(x∗)≤f(x) for all x∈Ax\in Ax∈A.

The extremum is strict if the inequality is strict for all x∈A∖{x∗}x\in A\setminus\{x^\ast\}x∈A∖{x∗}.

Interpretation¶

A global extremum compares the candidate with every feasible point. Strictness means there is no other feasible point with the same optimal value.

Key Results¶

  • A strict global maximum or minimum has a unique optimizer.
  • A continuous function on a compact feasible set attains both a global maximum and a global minimum.
  • A global extremum is automatically local when neighbourhoods inside the feasible set are considered.
