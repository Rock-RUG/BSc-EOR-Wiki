Complementary Slackness¶

Definition¶

For an inequality constraint written as ci(x)≤0c_i(x)\le 0ci​(x)≤0 with multiplier λi≥0\lambda_i\ge 0λi​≥0, complementary slackness is the condition

λici(x∗)=0.\lambda_i c_i(x^\ast)=0.λi​ci​(x∗)=0.

Equivalently, either the constraint is binding or its multiplier is zero.

Interpretation¶

Complementary slackness says that a constraint can matter through its multiplier only when it is actually tight.

Key Results¶

  • If ci(x∗)<0c_i(x^\ast)<0ci​(x∗)<0, then λi=0\lambda_i=0λi​=0.
  • If λi>0\lambda_i>0λi​>0, then ci(x∗)=0c_i(x^\ast)=0ci​(x∗)=0.
  • The condition is part of the Kuhn-Tucker system for inequality-constrained optimization.

Examples¶

  • If x≤4x\le 4x≤4 is written as x−4≤0x-4\le 0x−4≤0 and the optimum has x=3x=3x=3, then the multiplier must be 000.
  • If a multiplier for x≤4x\le 4x≤4 is positive, then the optimum must satisfy x=4x=4x=4.
