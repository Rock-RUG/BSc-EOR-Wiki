Augmenting Path Algorithm¶

Definition¶

The augmenting path algorithm starts with a feasible flow, initially zero in the course examples. Find a source-to-sink augmenting path, augment by its bottleneck δ\deltaδ, decrease each traversed residual capacity by δ\deltaδ, increase the opposite residual capacity by δ\deltaδ, and repeat. If no augmenting path remains, the current flow is maximum.

Interpretation¶

The augmenting path algorithm builds a maximum flow step by step: as long as some route from source to sink still has spare capacity, it sends as much as that route allows. The residual network keeps track of the spare capacity and allows both new routing and correction of earlier routing.

The figure runs the algorithm from zero flow on the network of the augmenting path figure. Three paths are found, with bottlenecks 333, 333 and 222, raising the flow value to 333, 666 and 888. At the end both edges into FFF are full: D−FD-FD−F carries 555 and E−FE-FE−F carries 333. Every unit reaching FFF uses one of them, so no flow can exceed 888: the stopping condition has certified a maximum.

The reverse residual directions are not a technicality. Take edges S→AS\to AS→A, S→BS\to BS→B, A→BA\to BA→B, A→TA\to TA→T and B→TB\to TB→T, all of capacity 111. After a first path S−A−B−TS-A-B-TS−A−B−T, no forward route with spare capacity is left, although the maximum flow is 222. The reverse residual B→AB\to AB→A of the used edge A→BA\to BA→B gives the path S−B−A−TS-B-A-TS−B−A−T, which cancels that unit on A→BA\to BA→B and reaches the maximum.

The final flow value does not depend on which augmenting paths are chosen, although the flows on individual edges can. A common slip is to read the final residual capacities as flows: the flow on an original edge equals its reverse residual.

Key Results¶

  • Maintain flow conservation after every augmentation.
  • The integer capacities in the exercises allow integer augmentations and finite termination.
  • Recover original flows from the final residual values, taking edge directions into account.

Examples¶

On an original forward edge the augmentation adds δ\deltaδ to its flow; on a backward residual edge it subtracts δ\deltaδ. With integer capacities and an integral starting flow, each augmentation increases the value by at least 1, so only finitely many are possible.

  • The main example augments by 5,2,1,4,1,25,2,1,4,1,25,2,1,4,1,2, totalling 15.
  • The last residual network cannot reach the sink T from the source S through positive residual directions.
