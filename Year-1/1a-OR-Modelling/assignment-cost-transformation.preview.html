Assignment Cost Transformation¶

Proposition¶

In a square one-to-one assignment problem, adding a constant aia_iai​ to every cost in row iii, or a constant bjb_jbj​ to every cost in column jjj, preserves the set of optimal assignments. Every complete assignment's cost changes by the same total ∑iai+∑jbj\sum_i a_i+\sum_j b_j∑i​ai​+∑j​bj​.

Interpretation¶

Every assignment uses each row and each column exactly once. Uniform changes along a row or column therefore change the baseline cost without changing which assignment is best.

Key Results¶

  • Subtracting row and column minima is a valid transformation.
  • The Hungarian uncovered-entry adjustment is equivalent to suitable row and column changes.
  • For a maximum-profit assignment, negate profits and add a constant large enough to make the resulting costs nonnegative.

Examples¶

  • If row minima are 2, 5, 6, and 4, subtracting them reduces every assignment cost by 17.
  • Transforming profits pijp_{ij}pij​ into costs M−pijM-p_{ij}M−pij​ changes a complete assignment objective to nM−∑ipi,π(i)nM-\sum_i p_{i,\pi(i)}nM−∑i​pi,π(i)​.
