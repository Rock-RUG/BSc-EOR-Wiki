Maximum Flow Linear Program¶

Definition¶

For the course network with only outgoing source edges and only incoming sink edges, the maximum flow LP uses continuous variables xijx_{ij}xij​ and solves

max⁡∑jxsjsubject to∑jxji=∑jxij(i≠s,t),0≤xij≤cijfor every directed edge (i,j).\begin{aligned} \max\quad &\sum_jx_{sj}\\ \text{subject to}\quad &\sum_jx_{ji}=\sum_jx_{ij}\quad(i\ne s,t),\\ &0\le x_{ij}\le c_{ij}\quad\text{for every directed edge }(i,j). \end{aligned}maxsubject to​j∑​xsj​j∑​xji​=j∑​xij​(i=s,t),0≤xij​≤cij​for every directed edge (i,j).​

Here cijc_{ij}cij​ is the edge capacity and sums run over existing edges.

Interpretation¶

The formulation separates the objective at the source from conservation at intermediate vertices. Capacities constrain individual directed flows.

Key Results¶

  • Source outflow equals sink inflow by summing conservation equations.
  • No binary selection variable is needed: an edge may carry any feasible flow amount.
  • The formulation is derived from the video prompt and the previously taught flow conditions.
