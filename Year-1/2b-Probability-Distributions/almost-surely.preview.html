Almost Surely¶

Definition¶

Fix a sample space SSS with a probability function P\mathbb{P}P. An event AAA happens almost surely (a.s.), or with probability one (w.p.1), if

P(A)=1.\mathbb{P}(A)=1.P(A)=1.

Equivalently, its complement has probability zero. More generally, a statement about outcomes holds almost surely if the set of outcomes where it fails is contained in an event of probability zero.

Two random variables XXX and YYY on the same sample space are equal almost surely, written X=YX=YX=Y a.s., if

P(X=Y)=1.\mathbb{P}(X=Y)=1.P(X=Y)=1.

In the same way, X≤YX\le YX≤Y a.s. means P(X≤Y)=1\mathbb{P}(X\le Y)=1P(X≤Y)=1, and XXX is almost surely constant if P(X=c)=1\mathbb{P}(X=c)=1P(X=c)=1 for some number ccc.

Interpretation¶

"Almost" is there because the exceptional set need not be empty: it may contain outcomes that are perfectly possible, yet carry total probability zero. Probability one is therefore not the same as "for every outcome", and probability zero is not the same as "impossible".

The figure takes the sample space (0,1)(0,1)(0,1) with probability equal to length, and U(u)=uU(u)=uU(u)=u, so U∼Unif⁡(0,1)U\sim\operatorname{Unif}(0,1)U∼Unif(0,1). The variable YYY from the Examples follows the same line as UUU except at the single outcome u=12u=\tfrac{1}{2}u=21​, where it drops to 000. The outcome u=12u=\tfrac{1}{2}u=21​ is perfectly possible, yet the event {Y≠U}={U=12}\{Y\neq U\}=\{U=\tfrac{1}{2}\}{Y=U}={U=21​} has probability zero, so Y=UY=UY=U almost surely. The dashed line 1−U1-U1−U shows the reverse situation: it has the same distribution as UUU but meets it only at u=12u=\tfrac{1}{2}u=21​, so UUU and 1−U1-U1−U are almost surely different.

For expectations, variances and distributions, what happens on an event of probability zero is invisible, so random variables that are equal almost surely can be treated as the same.

The phrase is essential for limit statements such as the strong law of large numbers, which concern the whole sequence X1,X2,…X_1,X_2,\ldotsX1​,X2​,… at once. "The sample mean converges to μ\muμ almost surely" allows some outcomes on which it does not converge, as long as together they have probability zero.

Equality almost surely is much stronger than equality in distribution. Equal distributions only say that XXX and YYY take values with the same probabilities; almost-sure equality says that they take the same value on (almost) every outcome.

Key Results¶

  • If A1,A2,…A_1,A_2,\ldotsA1​,A2​,… each happen almost surely, then so does ⋂nAn\bigcap_{n}A_n⋂n​An​, because the union of countably many probability-zero events has probability zero. In particular, X=YX=YX=Y a.s. and Y=ZY=ZY=Z a.s. give X=ZX=ZX=Z a.s.
  • If X=YX=YX=Y a.s., then XXX and YYY have the same distribution, and EX=EY\mathbb{E}X=\mathbb{E}YEX=EY whenever either side exists. The converse fails: the same distribution does not imply almost sure equality.
  • If X≤YX\le YX≤Y a.s. and both expectations exist, then EX≤EY\mathbb{E}X\le\mathbb{E}YEX≤EY (monotonicity of expectation).
  • If X≥0X\ge0X≥0 and EX=0\mathbb{E}X=0EX=0, then X=0X=0X=0 a.s. By the Markov inequality, P(X≥1/n)≤n EX=0\mathbb{P}(X\ge1/n)\le n\,\mathbb{E}X=0P(X≥1/n)≤nEX=0 for every nnn, and {X>0}=⋃n{X≥1/n}\{X>0\}=\bigcup_n\{X\ge1/n\}{X>0}=⋃n​{X≥1/n} is a countable union of null events.
  • Var⁡(X)=0\operatorname{Var}(X)=0Var(X)=0 if and only if X=EXX=\mathbb{E}XX=EX a.s. (variance). This is the previous result applied to (X−EX)2(X-\mathbb{E}X)^2(X−EX)2, or equivalently the Chebyshev inequality with σ2=0\sigma^2=0σ2=0.

Heads appears eventually almost surely, even though the all-tails sequence is a possible outcome.
