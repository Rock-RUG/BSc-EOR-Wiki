Matrix Product¶

Definition¶

If A\boldsymbol{A}A has size m×nm\times nm×n and B\boldsymbol{B}B has size n×kn\times kn×k, the matrix product AB\boldsymbol{A}\boldsymbol{B}AB is the m×km\times km×k matrix with entries (AB)ij=∑r=1nairbrj\displaystyle (\boldsymbol{A}\boldsymbol{B})_{ij}=\sum_{r=1}^n a_{ir}b_{rj}(AB)ij​=r=1∑n​air​brj​.

Interpretation¶

Matrix multiplication combines rows of the left matrix with columns of the right matrix and represents composition of linear maps: (AB)x=A(Bx)(\boldsymbol{A}\boldsymbol{B})\boldsymbol{x}=\boldsymbol{A}(\boldsymbol{B}\boldsymbol{x})(AB)x=A(Bx). The row-times-column rule is exactly what makes this hold.

The entry c22=a21b12+a22b22+a23b32c_{22}=a_{21}b_{12}+a_{22}b_{22}+a_{23}b_{32}c22​=a21​b12​+a22​b22​+a23​b32​ is obtained by multiplying row 222 of A\boldsymbol{A}A by column 222 of B\boldsymbol{B}B. Both have three entries, which is why the inner sizes of the 2×32\times32×3 and 3×23\times23×2 matrices must agree; the outer sizes give the 2×22\times22×2 size of the product.

A second reading uses columns. If a1,…,an\boldsymbol{a}_1,\ldots,\boldsymbol{a}_na1​,…,an​ are the columns of A\boldsymbol{A}A, then Ax=x1a1+⋯+xnan\boldsymbol{A}\boldsymbol{x}=x_1\boldsymbol{a}_1+\cdots+x_n\boldsymbol{a}_nAx=x1​a1​+⋯+xn​an​ is a linear combination of these columns, and column jjj of AB\boldsymbol{A}\boldsymbol{B}AB is A\boldsymbol{A}A times column jjj of B\boldsymbol{B}B. In the second Example, 3(10)+4(21)=(114)3\begin{pmatrix}1\\0\end{pmatrix}+4\begin{pmatrix}2\\1\end{pmatrix}=\begin{pmatrix}11\\4\end{pmatrix}3(10​)+4(21​)=(114​). With this reading, a linear system Ax=b\boldsymbol{A}\boldsymbol{x}=\boldsymbol{b}Ax=b asks for a combination of the columns of A\boldsymbol{A}A that equals b\boldsymbol{b}b.

The order of the factors matters. When AB\boldsymbol{A}\boldsymbol{B}AB is defined, BA\boldsymbol{B}\boldsymbol{A}BA may not be, and even for square matrices the two usually differ: for A=(0100)\boldsymbol{A}=\begin{pmatrix}0&1\\0&0\end{pmatrix}A=(00​10​) and B=(0010)\boldsymbol{B}=\begin{pmatrix}0&0\\1&0\end{pmatrix}B=(01​00​), AB=(1000)\boldsymbol{A}\boldsymbol{B}=\begin{pmatrix}1&0\\0&0\end{pmatrix}AB=(10​00​) but BA=(0001)\boldsymbol{B}\boldsymbol{A}=\begin{pmatrix}0&0\\0&1\end{pmatrix}BA=(00​01​). A common slip is to multiply matrices entry by entry, as for matrix addition; that is a different operation.

Key Results¶

  • The product AB\boldsymbol{A}\boldsymbol{B}AB is defined only when the number of columns of A\boldsymbol{A}A equals the number of rows of B\boldsymbol{B}B.
  • Matrix multiplication is associative and distributive, but not generally commutative.
