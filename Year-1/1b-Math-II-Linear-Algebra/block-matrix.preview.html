Block Matrix¶

Definition¶

A block matrix is a matrix viewed as being partitioned into smaller matrices called blocks or submatrices.

A block diagonal matrix is a square block matrix of the form

(A10⋯00A2⋯0⋮⋮⋱⋮00⋯Ak),\begin{pmatrix} A_1&0&\cdots&0\\ 0&A_2&\cdots&0\\ \vdots&\vdots&\ddots&\vdots\\ 0&0&\cdots&A_k \end{pmatrix},​A1​0⋮0​0A2​⋮0​⋯⋯⋱⋯​00⋮Ak​​​,

where A1,…,AkA_1,\ldots,A_kA1​,…,Ak​ are square matrices.

Interpretation¶

Block notation lets us calculate with large matrices by treating compatible submatrices as entries. Block diagonal matrices represent independent components that do not interact across blocks.

Key Results¶

  • Compatible block matrices can be added and multiplied block-by-block using the usual matrix rules.
  • If AAA is block diagonal with diagonal blocks A1,…,AkA_1,\ldots,A_kA1​,…,Ak​, then
det⁡(A)=det⁡(A1)det⁡(A2)⋯det⁡(Ak).\det(A)=\det(A_1)\det(A_2)\cdots\det(A_k).det(A)=det(A1​)det(A2​)⋯det(Ak​).

Examples¶

  • (A11A12A21A22)\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix}(A11​A21​​A12​A22​​) is a matrix written in four blocks.
  • (A100A2)\begin{pmatrix}A_1&0\\0&A_2\end{pmatrix}(A1​0​0A2​​) is block diagonal.
