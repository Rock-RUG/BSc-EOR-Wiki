Cantor's Theorem¶

Theorem¶

Cantor's theorem states that for every set AAA,

card⁡(A)<card⁡(2A),\operatorname{card}(A)<\operatorname{card}(2^A),card(A)<card(2A),

where 2A2^A2A is the power set of AAA.

Interpretation¶

No function from a set to its power set can be surjective. Thus the power set is always strictly larger than the original set.

Key Results¶

  • There is an infinite staircase of larger and larger infinities: A,2A,22A,…A,2^A,2^{2^A},\ldotsA,2A,22A,….
  • A bijection is the main tool for proving that two sets have the same cardinality.

Examples¶

  • For A=NA=\mathbb NA=N, the power set 2N2^{\mathbb N}2N has larger cardinality than N\mathbb NN.
  • The natural numbers N\mathbb NN are the standard example of a countably infinite set.
