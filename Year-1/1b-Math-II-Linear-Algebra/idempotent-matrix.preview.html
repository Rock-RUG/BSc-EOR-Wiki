Idempotent Matrix¶

Definition¶

An idempotent matrix, or projection matrix, is a real square matrix P\boldsymbol{P}P satisfying P2=P\boldsymbol{P}^2=\boldsymbol{P}P2=P.

Such a matrix projects onto its range: it maps every vector into the subspace range⁡(P)\operatorname{range}(\boldsymbol{P})range(P) and leaves every vector of that subspace unchanged. A projection matrix that is also symmetric, P⊤=P\boldsymbol{P}^{\top}=\boldsymbol{P}P⊤=P, is an orthogonal projection matrix; the others are oblique projections. In statistics and econometrics "projection matrix" usually means the orthogonal case, such as the hat matrix X(X⊤X)−1X⊤\boldsymbol{X}(\boldsymbol{X}^{\top}\boldsymbol{X})^{-1}\boldsymbol{X}^{\top}X(X⊤X)−1X⊤ of least squares, for X\boldsymbol{X}X of full column rank.

Interpretation¶

The square P2\boldsymbol{P}^2P2 is a matrix product, representing two successive applications of the same linear map. Idempotence says this composition equals one application.

Applying an idempotent matrix twice has the same effect as applying it once: projecting a vector that already lies in the subspace leaves it where it is.

A2=A\boldsymbol{A}^2=\boldsymbol{A}A2=A: A(Av)=Av\boldsymbol{A}(\boldsymbol{A}\boldsymbol{v})=\boldsymbol{A}\boldsymbol{v}A(Av)=Av, so vectors of range⁡A\operatorname{range}\boldsymbol{A}rangeA stay fixed (Aw=w\boldsymbol{A}\boldsymbol{w}=\boldsymbol{w}Aw=w) and ker⁡A\ker \boldsymbol{A}kerA is killed (Ak=0\boldsymbol{A}\boldsymbol{k}=\boldsymbol{0}Ak=0). Every v\boldsymbol{v}v splits as w+k\boldsymbol{w}+\boldsymbol{k}w+k with w∈range⁡A\boldsymbol{w}\in\operatorname{range}\boldsymbol{A}w∈rangeA, k∈ker⁡A\boldsymbol{k}\in\ker \boldsymbol{A}k∈kerA (a direct sum). The eigenvalues are 000 and 111 only; the projection need not be orthogonal (here it is oblique).

Key Results¶

  • The zero square matrix and identity matrix are idempotent.
  • If an idempotent matrix is invertible, then it equals the identity matrix.
  • If P\boldsymbol{P}P is idempotent, then every vector splits as v=Pv+(v−Pv)\boldsymbol{v}=\boldsymbol{P}\boldsymbol{v}+(\boldsymbol{v}-\boldsymbol{P}\boldsymbol{v})v=Pv+(v−Pv) with Pv∈range⁡(P)\boldsymbol{P}\boldsymbol{v}\in\operatorname{range}(\boldsymbol{P})Pv∈range(P) and v−Pv∈ker⁡(P)\boldsymbol{v}-\boldsymbol{P}\boldsymbol{v}\in\ker(\boldsymbol{P})v−Pv∈ker(P), so the space is the direct sum range⁡(P)⊕ker⁡(P)\operatorname{range}(\boldsymbol{P})\oplus\ker(\boldsymbol{P})range(P)⊕ker(P): P\boldsymbol{P}P projects onto its range along its kernel.
  • If P\boldsymbol{P}P is idempotent, so is I−P\boldsymbol{I}-\boldsymbol{P}I−P; it projects onto ker⁡(P)\ker(\boldsymbol{P})ker(P) along range⁡(P)\operatorname{range}(\boldsymbol{P})range(P).
  • The only possible eigenvalues of an idempotent matrix are 000 and 111.
  • An orthogonal projection matrix is symmetric and idempotent; then Pv\boldsymbol{P}\boldsymbol{v}Pv is the point of range⁡(P)\operatorname{range}(\boldsymbol{P})range(P) closest to v\boldsymbol{v}v, and v−Pv\boldsymbol{v}-\boldsymbol{P}\boldsymbol{v}v−Pv is orthogonal to range⁡(P)\operatorname{range}(\boldsymbol{P})range(P).

  • (1000)\begin{pmatrix}1&0\\0&0\end{pmatrix}(10​00​) is idempotent and symmetric: the orthogonal projection onto the xxx-axis.
  • (1100)\begin{pmatrix}1&1\\0&0\end{pmatrix}(10​10​) is idempotent but not symmetric: an oblique projection onto the xxx-axis along the line spanned by (1,−1)(1,-1)(1,−1).
