Homogeneous and Inhomogeneous Systems¶

Definition¶

A linear system Ax=bAx=bAx=b is homogeneous if b=0b=\boldsymbol 0b=0. It is inhomogeneous if b≠0b\neq\boldsymbol 0b=0.

Interpretation¶

A homogeneous system asks which vectors are mapped to zero. An inhomogeneous system asks which vectors are mapped to a specified nonzero right-hand side.

Ax=0Ax=0Ax=0 (here x1+2x2=0x_1+2x_2=0x1​+2x2​=0): the solutions form the subspace ker⁡A\ker AkerA, so 000 is always a solution and solutions can be added and scaled; for Ax=bAx=bAx=b (here x1+2x2=3x_1+2x_2=3x1​+2x2​=3) the solution set is xp+ker⁡Ax_p+\ker Axp​+kerA or empty.

Key Results¶

  • A homogeneous system always has at least the trivial solution x=0x=\boldsymbol 0x=0.
  • If a homogeneous system has more than one solution, then it has infinitely many solutions.
  • An inhomogeneous system may have no solution, one solution, or infinitely many solutions.

Examples¶

  • Ax=0Ax=\boldsymbol 0Ax=0 is homogeneous.
  • Ax=bAx=bAx=b with b≠0b\neq\boldsymbol 0b=0 is inhomogeneous.
