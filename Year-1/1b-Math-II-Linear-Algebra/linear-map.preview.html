Linear Map¶

Definition¶

Let F\mathbb FF be a field, and let VVV and WWW be vector spaces over F\mathbb FF. A linear map A:V→WA:V\to WA:V→W is a function satisfying additivity A(u+v)=Au+AvA(u+v)=Au+AvA(u+v)=Au+Av and homogeneity A(λu)=λAuA(\lambda u)=\lambda AuA(λu)=λAu.

Interpretation¶

A linear map preserves the linear structure of a vector space: it respects vector addition and scalar multiplication.

Key Results¶

  • A linear map is completely determined by what it does to a basis of its domain.
  • The set L(V,W)\mathcal L(V,W)L(V,W) of all linear maps from VVV to WWW is itself a vector space.
