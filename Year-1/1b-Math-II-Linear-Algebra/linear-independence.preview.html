Linear Dependence and Independence¶

Definition¶

A collection (v1,v2,…,vk)(\boldsymbol{v}_1,\boldsymbol{v}_2,\ldots,\boldsymbol{v}_k)(v1​,v2​,…,vk​) of vectors is linearly dependent if there exist scalars α1,…,αk\alpha_1,\ldots,\alpha_kα1​,…,αk​, not all zero, such that

α1v1+α2v2+⋯+αkvk=0.\alpha_1\boldsymbol{v}_1+\alpha_2\boldsymbol{v}_2+\cdots+\alpha_k\boldsymbol{v}_k=\boldsymbol{0}.α1​v1​+α2​v2​+⋯+αk​vk​=0.

The collection is linearly independent if this can only happen when

α1=α2=⋯=αk=0.\alpha_1=\alpha_2=\cdots=\alpha_k=0.α1​=α2​=⋯=αk​=0.

Interpretation¶

Linear dependence means that at least one vector is redundant because it can be written using the others. Linear independence means that no vector in the collection is redundant: the only combination that gives 0\boldsymbol{0}0 is the one with all coefficients zero.

This is why a basis must be independent. Two vectors are dependent if and only if one is a scalar multiple of the other, and three vectors in R3\mathbb{R}^3R3 are dependent if and only if they lie in one plane through the origin.

Key Results¶

  • A collection is linearly independent if and only if every vector in its span has a unique expression as a linear combination of the collection.
  • Any collection containing the zero vector, a repeated vector, or a scalar multiple of another vector is linearly dependent.

Examples¶

  • In R2\mathbb{R}^2R2, (1,0)(1,0)(1,0) and (0,1)(0,1)(0,1) are linearly independent.
  • In R2\mathbb{R}^2R2, (1,0)(1,0)(1,0) and (2,0)(2,0)(2,0) are linearly dependent, since (2,0)=2(1,0)(2,0)=2(1,0)(2,0)=2(1,0).
