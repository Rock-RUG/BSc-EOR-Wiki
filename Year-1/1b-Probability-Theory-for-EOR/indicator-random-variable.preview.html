Indicator Random Variable¶

Definition¶

Let AAA be an event. The indicator random variable of AAA is the random variable 1A\mathbf 1_A1A​ defined by

1A(ω)={1,ω∈A,0,ω∉A.\mathbf 1_A(\omega)= \begin{cases} 1,&\omega\in A,\\ 0,&\omega\notin A. \end{cases}1A​(ω)={1,0,​ω∈A,ω∈/A.​

Interpretation¶

An indicator turns an event into a numerical variable. It records whether the event happened using one for yes and zero for no.

Key Results¶

  • An indicator random variable takes only the values zero and one.
  • Its expectation equals the probability of the event it indicates.
  • A sum of indicators counts how many events occur.

Examples¶

  • Let an indicator equal one if a customer returns a product and zero otherwise.
  • In occupancy problems, each box can have an indicator for being nonempty.
  • In network reliability, each component can have an indicator for working.
