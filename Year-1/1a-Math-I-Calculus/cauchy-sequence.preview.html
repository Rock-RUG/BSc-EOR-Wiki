Cauchy Sequence¶

Definition¶

Enrichment: non-assessable in 2026-27

Interpretation¶

A Cauchy sequence is one whose terms eventually become arbitrarily close to each other.

This definition characterises convergence using only internal comparisons between sequence elements.

Key Results¶

  • Cauchy criterion. A sequence of real numbers is convergent if and only if it is a Cauchy sequence. This is special to complete number systems such as R;\mathbb{R}\text{;}R; the course uses it as a criterion and does not construct R\mathbb{R}R from Cauchy sequences.
