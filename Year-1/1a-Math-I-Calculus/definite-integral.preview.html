Definite Integral¶

Definition¶

Let a,b∈Ra,b\in\mathbb{R}a,b∈R with a<b.a<b\text{.}a<b. Suppose f ⁣:I→Rf\colon I\to\mathbb{R}f:I→R is a Riemann integrable function on I=[a,b].I=[a,b]\text{.}I=[a,b]. The following expression

∫abf(x) dx\int_a^b f(x) \,\mathrm{d}x∫ab​f(x)dx

is referred to as a definite integral, which is a real number, not a function of x.x\text{.}x.

The symbol ∫\int∫ is a stylized "S" for "sum", while dx\mathrm{d}xdx records the variable and the limiting width:

Here xi∗x_i^*xi∗​ is any point in [a+(i−1)(b−a)/n, a+i(b−a)/n][a+(i-1)(b-a)/n,\,a+i(b-a)/n][a+(i−1)(b−a)/n,a+i(b−a)/n], the iiith subinterval of the regular subdivision.

Interpretation¶

The definite integral ∫abf(x) dx\int_a^b f(x)\,\mathrm{d}x∫ab​f(x)dx is a single number that adds up the values of fff over [a,b][a,b][a,b], each weighted by the length over which it holds: it is the limit of the sums ∑f(xi∗)b−an\displaystyle \sum f(x_i^*)\frac{b-a}{n}∑f(xi∗​)nb−a​ in the Definition. Geometrically it is a net area.

The figure shows f(x)=sin⁡xf(x)=\sin xf(x)=sinx from aaa to a point bbb beyond π\piπ. Up to π\piπ the graph lies above the axis, and the blue area counts positively; between π\piπ and bbb it lies below the axis, and the red area counts negatively. The integral is blue minus red, so it is smaller than the total shaded area.

Each part of the notation has a role. The integrand fff supplies the heights, aaa and bbb fix the interval, and dx\mathrm{d}xdx names the variable of integration and stands for the shrinking widths b−an\frac{b-a}{n}nb−a​. The variable is a dummy, so the value does not depend on xxx: ∫abf(x) dx\int_a^b f(x)\,\mathrm{d}x∫ab​f(x)dx is a number, while ∫axf(t) dt\int_a^x f(t)\,\mathrm{d}t∫ax​f(t)dt is a function of its upper limit.

The fundamental theorem of calculus evaluates a definite integral as F(b)−F(a)F(b)-F(a)F(b)−F(a) for an antiderivative FFF, so in practice it is rarely computed from sums.

A common slip is to read the integral as the area itself. Signed area and area differ when fff changes sign: ∫−11x dx=0\int_{-1}^1 x\,\mathrm{d}x=0∫−11​xdx=0, although the region between the graph and the axis has area ∫−11∣x∣ dx=1\int_{-1}^1|x|\,\mathrm{d}x=1∫−11​∣x∣dx=1.

Later, improper integrals extend the definite integral to unbounded intervals and integrands.

Key Results¶

  • If fff is integrable on [a,b][a,b][a,b] and a<c<b,a<c<b\text{,}a<c<b, then ∫abf=∫acf+∫cbf.\displaystyle\int_a^b f=\int_a^c f+\int_c^b f\text{.}∫ab​f=∫ac​f+∫cb​f.
  • The value of a definite integral does not depend on any partition: refining a partition can only decrease upper sums and increase lower sums, and for an integrable function both approach the same number.
  • A definite integral measures signed area: regions above the xxx-axis contribute positively and regions below contribute negatively. When f≥0,f\geq0\text{,}f≥0, it agrees with the ordinary area under the graph.
  • By convention, ∫baf=−∫abf\displaystyle\int_b^a f=-\int_a^b f∫ba​f=−∫ab​f for a<ba<ba<b and ∫aaf=0;\displaystyle\int_a^a f=0\text{;}∫aa​f=0; hence reversing the limits always changes the sign: ∫uvf=−∫vuf.\displaystyle\int_u^v f=-\int_v^u f\text{.}∫uv​f=−∫vu​f.
  • Varying an endpoint produces the functions F(x)=∫axf(t) dt\displaystyle F(x)=\int_a^x f(t)\,\mathrm{d}tF(x)=∫ax​f(t)dt and G(x)=∫xbf(t) dt\displaystyle G(x)=\int_x^b f(t)\,\mathrm{d}tG(x)=∫xb​f(t)dt on [a,b],[a,b]\text{,}[a,b], with F(a)=0F(a)=0F(a)=0 and G(b)=0.G(b)=0\text{.}G(b)=0. Write ∫axf(t) dt,\int_a^x f(t)\,\mathrm{d}t\text{,}∫ax​f(t)dt, never ∫axf(x) dx,\int_a^x f(x)\,\mathrm{d}x\text{,}∫ax​f(x)dx, since the latter uses xxx in two different roles.

  • A definite integral does not depend on the name of the integration variable, i.e.,

    ∫abf(x) dx=∫abf(y) dy.\int_a^b f(x)\,\mathrm{d}x=\int_a^b f(y)\,\mathrm{d}y.∫ab​f(x)dx=∫ab​f(y)dy.
