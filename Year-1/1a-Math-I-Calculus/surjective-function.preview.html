Surjective Function¶

Definition¶

A function f ⁣:X→Yf\colon X\to Yf:X→Y is surjective if for every y∈Y,y \in Y\text{,}y∈Y, there exists an x∈Xx \in Xx∈X such that f(x)=y.f (x) = y\text{.}f(x)=y. In other words, a function is onto if its codomain is exactly its range.

Interpretation¶

Surjectivity describes how completely a function covers its codomain: every element of YYY must be the output of at least one input, so no element of the codomain is left unused.

In the left diagram each of the three points of YYY receives at least one arrow, the top one even two, so the function is surjective; sharing an output is allowed. In the right diagram the bottom point of YYY, drawn hollow, receives no arrow, so that function is not surjective, even though every input is used.

To prove surjectivity, take an arbitrary y∈Yy\in Yy∈Y and find an x∈Xx\in Xx∈X with f(x)=yf(x)=yf(x)=y, usually by solving this equation for xxx. For f(x)=x3f(x)=x^3f(x)=x3 on R\mathbb{R}R the solution is x=y3x=\sqrt[3]{y}x=3y​. To disprove it, a single yyy without a solution suffices, as y=−1y=-1y=−1 shows for x2x^2x2 on R\mathbb{R}R. In terms of the range, fff is surjective if and only if its range equals YYY; for a function on a subset of R\mathbb{R}R, every horizontal line y=cy=cy=c with c∈Yc\in Yc∈Y must meet the graph at least once.

Surjectivity is a property of the rule together with the codomain: with codomain [0,+∞)[0,+\infty)[0,+∞) instead of R\mathbb{R}R, the function x2x^2x2 becomes surjective. Together with injectivity it makes fff a bijection: surjectivity guarantees at least one solution of f(x)=yf(x)=yf(x)=y, injectivity at most one.

A common slip is to check the inputs instead of the outputs. That every input has an output is true for every function; surjectivity is about every element of the codomain.

Key Results¶

  • A function is surjective if every element of the codomain is attained.
  • Surjectivity depends on both the function rule and the chosen codomain.
  • Changing the codomain may change surjectivity.
  • The unique function from the empty set to itself is surjective: both its range and codomain are empty. There is no function from a nonempty domain to an empty codomain.
  • If f ⁣:X→Yf\colon X\to Yf:X→Y and g ⁣:Y→Zg\colon Y\to Zg:Y→Z are surjective, their composition is surjective onto ZZZ. The shared middle set matters: if ggg accepts a larger domain, it may reach some targets only from inputs that fff never produces.

Examples¶

  • The function f(x)=x3f(x)=x^3f(x)=x3 from R\mathbb{R}R to R\mathbb{R}R is surjective.
  • The function f(x)=x2f(x)=x^2f(x)=x2 from R\mathbb{R}R to R\mathbb{R}R is not surjective.
  • Let f ⁣:{0}→{0}f\colon\{0\}\to\{0\}f:{0}→{0} and g ⁣:{0,1}→{0,1}g\colon\{0,1\}\to\{0,1\}g:{0,1}→{0,1} be identity maps. Each is surjective, and g∘f ⁣:{0}→{0,1}g\circ f\colon\{0\}\to\{0,1\}g∘f:{0}→{0,1} is defined, but it misses 111. Individual surjectivity plus the general range-containment condition does not by itself ensure surjectivity of the composite.

Proving that a rational function is surjective

Let f ⁣:R∖{3}→R∖{2}f\colon\mathbb{R}\setminus\{3\}\to\mathbb{R}\setminus\{2\}f:R∖{3}→R∖{2} be given by f(x)=2x+1x−3f(x)=\dfrac{2x+1}{x-3}f(x)=x−32x+1​. Show that fff is surjective.

Since y≠2y\neq2y=2, this gives the candidate x=3y+1y−2x=\dfrac{3y+1}{y-2}x=y−23y+1​.

Check that the candidate lies in the domain

If 3y+1y−2=3\dfrac{3y+1}{y-2}=3y−23y+1​=3, then 3y+1=3y−63y+1=3y-63y+1=3y−6, that is 1=−61=-61=−6, which is false. So x≠3x\neq3x=3 and xxx lies in the domain.

Check that it really maps to yyy

With x=3y+1y−2x=\dfrac{3y+1}{y-2}x=y−23y+1​ we get 2x+1=7yy−22x+1=\dfrac{7y}{y-2}2x+1=y−27y​ and x−3=7y−2x-3=\dfrac{7}{y-2}x−3=y−27​, so

Every yyy in the codomain is reached, so fff is surjective.

Takeaway. Solving f(x)=yf(x)=yf(x)=y only suggests a candidate; check that it lies in the domain and maps to yyy. The codomain matters: as a map into all of R\mathbb{R}R, this fff is not surjective, because y=2y=2y=2 is never reached.
