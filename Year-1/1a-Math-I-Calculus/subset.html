    Subset¶

    Definition¶

    Let A,A\text{,}A, BBB be sets. We say that AAA is a subset of B,B\text{,}B, denoted A⊆B,A\subseteq B\text{,}A⊆B, if every element of AAA is also an element of B,B\text{,}B, i.e.,

    for any object x,  x∈A    ⟹    x∈B.\text{for any object }x,\; x\in A \; \implies\; x\in B.for any object x,x∈A⟹x∈B.

    Interpretation¶

    A subset describes containment between collections of objects.

    Key Results¶

    • Every set is a subset of itself.
    • Subset relations are transitive, i.e., A⊆BA\subseteq BA⊆B and B⊆CB\subseteq CB⊆C implies A⊆C.A\subseteq C\text{.}A⊆C.
    • Proper subsets exclude equality.

    Examples¶

    • {1, 2}⊆{1, 2, 3}.\{1,\,2\}\subseteq\{1,\,2,\,3\}\text{.}{1,2}⊆{1,2,3}.
    • ∅\varnothing∅ is a subset of every set.
