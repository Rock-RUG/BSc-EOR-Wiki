Bijection and Inverse Function¶

Definition¶

A function fff is invertible (or bijective) if it is both injective and surjective. If f ⁣:X→Yf\colon X\to Yf:X→Y is a bijection, then for every y∈Y,y\in Y\text{,}y∈Y, there is exactly one xxx such that f(x)=yf(x) = yf(x)=y (there is at least one because of surjectivity, and at most one because of injectivity). This value of xxx is denoted f−1(y);f^{-1}(y)\text{;}f−1(y); thus f−1f^{-1}f−1 is a function from YYY to X.X\text{.}X. We call f−1f^{-1}f−1 the inverse of f.f\text{.}f.

Interpretation¶

A bijection establishes a perfect correspondence between two sets: every element of the codomain is paired with exactly one element of the domain.

Invertibility formalises the idea that a function can be “reversed" without ambiguity, allowing inputs to be uniquely recovered from outputs.

Key Results¶

  • A function admits an inverse if and only if it is bijective.
  • The inverse of a bijection is itself a bijection.
  • Composition with an inverse recovers the identity function on both domain and codomain.
