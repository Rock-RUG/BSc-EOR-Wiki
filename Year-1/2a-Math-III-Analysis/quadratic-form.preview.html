Quadratic Form¶

This page presents the Math III: Analysis treatment. See also the treatment in Math II: Linear Algebra. Mastery is recorded separately for each course context.

Definition¶

A quadratic form is a polynomial from Rn\mathbb R^nRn to R\mathbb RR with terms all of degree two, i.e., a quadratic on Rn\mathbb R^nRn has the general expression:

where x=(x1 x2, …, xn)⊺\boldsymbol{x}=(x_1\,x_2,\,\dots,\,x_n)^\intercalx=(x1​x2​,…,xn​)⊺ and A=(aij)1≤i,j≤n\boldsymbol A=(a_{ij})_{1\leq i,j\leq n}A=(aij​)1≤i,j≤n​ is any nonzero n×nn\times nn×n matrix.

Interpretation¶

A quadratic form is a polynomial where every term has exactly two variables multiplied together, possibly the same variable squared.

It can always be written using a symmetric matrix that encodes all the coefficients.

Key Results¶

  • For any quadratic form, the associated matrix is not unique. However, there always exists a unique symmetric matrix A‾=(A+A⊺)/2\overline {\boldsymbol A}=(\boldsymbol A+\boldsymbol A^\intercal)/2A=(A+A⊺)/2 where A\boldsymbol AA is any associated matrix of the quadratic form.

Examples¶

  • f(x,y)=x2+y2f(x,y) = x^2 + y^2f(x,y)=x2+y2 is a quadratic form. Both terms are squares, degree two.
  • f(x,y)=3x2+4xy+5y2f(x,y) = 3x^2 + 4xy + 5y^2f(x,y)=3x2+4xy+5y2 is a quadratic form. It includes a square term, a cross term, and another square term.
