Heine-Borel Theorem¶

Theorem¶

Let E\boldsymbol{E}E be a subset of the Euclidean space Rn.\mathbb{R}^n\text{.}Rn. The set E\boldsymbol{E}E is compact if and only if it is both closed and bounded.

Interpretation¶

A set in Euclidean space is compact exactly when it contains all its limit points and stays within some finite distance from the origin. Closedness keeps the boundary in, boundedness keeps it from running off to infinity.

Key Results¶

  • The continuous image of a compact set is compact. This yields the extreme value theorem.
  • Any closed subset of a compact set in Rn\mathbb R^nRn is itself compact.
  • Finite unions of compact sets are compact. Arbitrary intersections of compact sets are compact.

Examples¶

  • A closed metric ball B‾(x0,r)={x∈X ⁣:d2(x,x0)≤r}\overline{\boldsymbol{B}}(\boldsymbol{x}_0,r) = \{\boldsymbol{x} \in \boldsymbol{X} \colon d_2(\boldsymbol{x}, \boldsymbol{x}_0) \leq r\}B(x0​,r)={x∈X:d2​(x,x0​)≤r} in the Euclidean space is closed and bounded, so compact.
  • Any finite set {x1,…,xk}⊂Rn\{\boldsymbol x_1,\dots,\boldsymbol x_k\}\subset \mathbb R^n{x1​,…,xk​}⊂Rn is closed (finite sets are closed) and bounded, so compact.
