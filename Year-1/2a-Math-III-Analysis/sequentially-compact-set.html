    Sequentially Compact Set¶

    Definition¶

    Let (X,dX)(\boldsymbol{X},d_{\boldsymbol{X}})(X,dX​) be a metric space. A subset E\boldsymbol{E}E of X\boldsymbol{X}X is termed sequentially compact if for every sequence (xi)i=1∞(\boldsymbol{x}_i)_{i=1}^\infty(xi​)i=1∞​ with each xi∈E,\boldsymbol{x}_i \in \boldsymbol{E}\text{,}xi​∈E, there exists a convergent subsequence (xij)j=1∞(\boldsymbol{x}_{i_j})_{j=1}^\infty(xij​​)j=1∞​ that converges to a point x∈E.\boldsymbol{x} \in \boldsymbol{E}\text{.}x∈E.

    Interpretation¶

    A set is sequentially compact if every infinite sequence drawn from it has a subsequence that converges to a point still inside the set.

    It captures the idea that the set is "closed under taking limits of subsequences."

    Key Results¶

    • In any metric space, a set is compact if and only if it is sequentially compact. This gives two equivalent ways to think about compactness: open covers or convergent subsequences.

    Examples¶

    • The closed unit ball {x∈Rn ⁣:∥x∥≤1}\{x\in \mathbb R^n\colon \|x\|\leq 1\}{x∈Rn:∥x∥≤1} is sequentially compact. This fails in infinite dimensions.
    • Any finite set in any metric space is compact.
