Key Results¶

  • The kkk-th order Taylor polynomial and the function fff have the same value and the same derivatives up to order kkk at x=a:x=a\text{:}x=a: Pk(j)(a)=f(j)(a)P_k^{(j)}(a)=f^{(j)}(a)Pk(j)​(a)=f(j)(a) for j=0,1,…,k.j=0,1,\dots,k\text{.}j=0,1,…,k. Away from aaa they generally differ.
  • One can write a Taylor polynomial for a function just from its first few derivatives, but the full Taylor series exists if the function is smooth, and the full series converges to the function on a neighbourhood of aaa if and only if the function is real analytic at aaa.
