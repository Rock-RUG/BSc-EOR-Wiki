Taylor Series¶

Proposition¶

Interpretation¶

If a function is so smooth that it behaves exactly like an infinite polynomial near a point,
then that polynomial is built entirely from its derivatives at that point.

Key Results¶

  • The Taylor series centered at the origin is called the Maclaurin series.
  • For any smooth function you can write down its Taylor series, but that series is guaranteed to converge to the function only if the function is real analytic.
