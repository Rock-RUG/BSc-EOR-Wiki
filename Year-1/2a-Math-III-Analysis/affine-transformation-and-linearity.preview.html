Affine Transformation and Linearity¶

Definition¶

Let n, k∈N+n,\,k \in\mathbb N^+n,k∈N+, let A∈Rk×n\boldsymbol A\in\mathbb R^{k\times n}A∈Rk×n be a k×nk\times nk×n real-valued matrix, and let b∈Rk\boldsymbol b\in\mathbb R^kb∈Rk be a column vector of real numbers. An affine transformation f ⁣:Rn→Rk\boldsymbol f\colon \mathbb R^n\to \mathbb R^kf:Rn→Rk is a function that can be represented as f(x)=Ax+b.\boldsymbol f(\boldsymbol x)=\boldsymbol A \boldsymbol x+ \boldsymbol b.f(x)=Ax+b. In the terminology of this Math III page, such affine functions are called linear functions. In particular, a linear real-valued function f ⁣:Rn→Rf\colon \mathbb R^n\to \mathbb Rf:Rn→R has the general expression:

f(x1, x2, …, xn)=a1x1+a2x2+⋯+anxn+b.f(x_1,\,x_2,\,\dots,\,x_n)=a_1x_1+a_2x_2+\cdots+a_nx_n+b.f(x1​,x2​,…,xn​)=a1​x1​+a2​x2​+⋯+an​xn​+b.

The term linear map/transformation, as used in linear algebra and on the Linear Transformation page, requires the additional condition b=0\boldsymbol b=\boldsymbol 0b=0. Thus an affine function with a nonzero constant term is not a linear map.

Interpretation¶

If one argument of an affine transformation is increased by ccc units, the function value changes by a constant multiple of ccc units.

Key Results¶

  • The graph of a linear real-valued function on Rn\mathbb R^nRn is a hyperplane of dimension nnn.
