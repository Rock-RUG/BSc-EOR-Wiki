Affine Map¶

Definition¶

Let n, k∈N+n,\,k \in\mathbb N^+n,k∈N+. A function f ⁣:Rn→Rk\boldsymbol f\colon \mathbb R^n\to \mathbb R^kf:Rn→Rk is an affine map (or affine transformation) if there are a k×nk\times nk×n real matrix A\boldsymbol AA and a vector b∈Rk\boldsymbol b\in\mathbb R^kb∈Rk such that

f(x)=Ax+bfor all x∈Rn.\boldsymbol f(\boldsymbol x)=\boldsymbol A \boldsymbol x+ \boldsymbol b\qquad\text{for all }\boldsymbol x\in\mathbb R^n.f(x)=Ax+bfor all x∈Rn.

A real-valued affine map f ⁣:Rn→Rf\colon \mathbb R^n\to \mathbb Rf:Rn→R (k=1k=1k=1) is an affine function:

f(x1, x2, …, xn)=a1x1+a2x2+⋯+anxn+b.\begin{aligned} &f(x_1,\,x_2,\,\dots,\,x_n)\\ &\quad=a_1x_1+a_2x_2+\cdots+a_nx_n+b. \end{aligned}​f(x1​,x2​,…,xn​)=a1​x1​+a2​x2​+⋯+an​xn​+b.​

Terminology

The Math III lecture notes, like much of economics and calculus, call an affine function a linear function and reserve linear transformation for the case b=0\boldsymbol b=\boldsymbol 0b=0. In linear algebra linear always means b=0\boldsymbol b=\boldsymbol 0b=0, so this wiki says affine for the general case.

Interpretation¶

An affine map is a linear map followed by a shift: if one argument is increased by ccc units, the value changes by ccc times a fixed vector, wherever the starting point is.

The blue linear map f(x)=2xf(x)=2xf(x)=2x passes through the origin. The red affine map g(x)=f(x)+1g(x)=f(x)+1g(x)=f(x)+1 is shifted upwards by 111, so g(0)=1g(0)=1g(0)=1 rather than 000.

Key Results¶

  • The graph {(x,f(x)) ⁣:x∈Rn}\{(\boldsymbol x,f(\boldsymbol x))\colon\boldsymbol x\in\mathbb R^n\}{(x,f(x)):x∈Rn} of an affine function on Rn\mathbb R^nRn is an affine hyperplane of Rn+1\mathbb R^{n+1}Rn+1; it passes through the origin exactly when b=0.b=0\text{.}b=0.
  • The level sets {x ⁣:f(x)=c}\{\boldsymbol x\colon f(\boldsymbol x)=c\}{x:f(x)=c} of a non-constant affine function are parallel affine hyperplanes of Rn\mathbb R^nRn.
  • A composition of affine maps is affine.
