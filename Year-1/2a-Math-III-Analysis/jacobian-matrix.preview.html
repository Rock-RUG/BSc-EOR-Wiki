Jacobian Matrix¶

Definition¶

For a function f ⁣:E→Rk\boldsymbol{f}\colon \boldsymbol{E}\to\mathbb{R}^kf:E→Rk that each of its partial derivatives exists at x=x0\boldsymbol{x}=\boldsymbol{x}_0x=x0​, the following k×nk\times nk×n matrix

is called the derivative matrix or the Jacobian matrix.

Interpretation¶

The Jacobian matrix is a matrix that stacks all the partial derivatives of a vector-valued function, showing how each output changes with each input.

Key Results¶

  • The total derivative of a differentiable function is equal to the Jacobian matrix.
  • The existence of the Jacobian matrix does not necessarily imply the total differentiability of the function.
