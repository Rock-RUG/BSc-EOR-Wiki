Lambda Function¶

Definition¶

A lambda function (λ\lambdaλ function) is an anonymous function: it is written down where it is used, without a name. The expression

x↦h(x)x\mapsto h(x)x↦h(x)

denotes the function that takes the argument xxx and returns h(x)h(x)h(x); the notes write it as λ ⁣:x↦h(x)\lambda\colon x\mapsto h(x)λ:x↦h(x). A lambda function may take a tuple of arguments, such as (x,y)↦x+y(x,y)\mapsto x+y(x,y)↦x+y, and it is a value like any other: it can be assigned a name, passed to another function or returned by one. In Python it is written lambda x: h(x), in R function(x) h(x).

Interpretation¶

A lambda function lets one general routine do many jobs: the routine fixes the pattern of the computation, and the lambda function supplies the small step that changes from task to task.

The figure shows Example 1. The routine Apply⁡\operatorname{Apply}Apply walks along the list and applies the lambda function to every entry, keeping the order; here the function is the indicator x↦1{x>3}x\mapsto\mathbf{1}\{x>3\}x↦1{x>3}, so each service time becomes 111 if it is long and 000 otherwise. Summing and dividing by n=4n=4n=4 gives the fraction of long services, 1/21/21/2.

The pattern needs two things to be right: the routine must call the function with the arguments it expects (one entry for Apply⁡\operatorname{Apply}Apply, a pair (m,xk)(m,x_k)(m,xk​) for Accumulate⁡\operatorname{Accumulate}Accumulate), and the start value must be neutral for the operation, 000 for a sum, 111 for a product and +∞+\infty+∞ for a minimum.

The same idea underlies LOTUS in Probability Theory: one routine Expectation⁡(pX,f)\operatorname{Expectation}(p_X,f)Expectation(pX​,f) computes E[f(X)]\mathbb{E}[f(X)]E[f(X)], and choosing fff as x↦xx\mapsto xx↦x, x↦x2x\mapsto x^2x↦x2 or y↦1{y≤x}y\mapsto\mathbf{1}\{y\leq x\}y↦1{y≤x} gives the mean, the second moment or the cdf. A frequent slip is to confuse a function with its value: a routine that returns a lambda function returns a function, not a number. A function that returns a lambda function which remembers values is a closure.
