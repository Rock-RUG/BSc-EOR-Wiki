Running and Hitting Costs¶

Definition¶

In a hitting problem a process moves from state to state until it enters a hitting set (also called a stopping set). A running cost R(x)R(x)R(x) is paid for every period the process spends in a state xxx outside the hitting set; a hitting cost (stopping cost) H(x)H(x)H(x) is paid once, when the process enters the hitting set at xxx. The expected total cost until stopping, V(x)V(x)V(x), satisfies

Interpretation¶

Running and hitting costs split the bill of one cycle into a meter that ticks every period and a single charge at the end. The recursion that adds them up does not care what the numbers mean, so one function computes both the expected cycle cost and the expected cycle length; only the pair (R,H)(R,H)(R,H) changes.
