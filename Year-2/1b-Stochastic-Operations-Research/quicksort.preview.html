Quicksort¶

Method¶

Quicksort sorts a list SSS in increasing order by recursion. QSort⁡(S)\operatorname{QSort}(S)QSort(S) does the following:

  1. if ∣S∣≤1|S|\leq1∣S∣≤1, return SSS;
  2. choose a pivot ppp uniformly at random from the entries of SSS;
  3. split SSS into the three lists L=[x∈S ⁣:x<p]L=[x\in S\colon x<p]L=[x∈S:x<p], M=[x∈S ⁣:x=p]M=[x\in S\colon x=p]M=[x∈S:x=p] and R=[x∈S ⁣:x>p]R=[x\in S\colon x>p]R=[x∈S:x>p], each keeping the entries in their original order;
  4. return the concatenation QSort⁡(L)+M+QSort⁡(R)\operatorname{QSort}(L)+M+\operatorname{QSort}(R)QSort(L)+M+QSort(R).

The middle list MMM contains the pivot and all its copies, so duplicates are handled correctly.

Interpretation¶

Quicksort solves a big sorting problem by solving two smaller ones: everything smaller than the pivot goes left, everything larger goes right, and once both sides are sorted the answer is just the pieces placed side by side.

The figure traces Example 1. Each box is one call; the orange entry is its pivot, and the three branches below lead to the parts LLL, MMM and RRR. Calls on lists with at most one entry return at once. Reading the leaves from left to right gives the green sorted list.

Two properties make the method work, and both can be checked by induction on the length of the list. Termination: MMM is never empty, so LLL and RRR are strictly shorter than SSS. Correctness: every entry of LLL is below every entry of MMM, which is below every entry of RRR, so concatenating sorted parts gives a sorted list. Using x≤px\leq px≤p for LLL breaks the first property, as Example 3 shows.

In the course the method is used mainly as a tool: merged arrival times of many patients must be put in time order before the gaps seen by the hospital can be computed, and the support of a pmf is sorted once to build its cdf. Sorting a sample turns it into its order statistics. A common slip is to sort the wrong sequence, such as the gaps instead of the arrival times.

Key Results¶

  • Every recursive call receives a strictly shorter list, so QSort⁡\operatorname{QSort}QSort terminates, and the output is a sorted rearrangement of the input: no entry is lost or duplicated, because LLL, MMM and RRR partition the entries of SSS.
  • With strict inequalities in LLL and RRR and equality in MMM, lists with repeated values are sorted correctly.
  • With a uniformly chosen pivot the expected number of comparisons grows like nlog⁡nn\log nnlogn for a list of nnn distinct entries; if the pivot were always the smallest entry, each call would remove one entry only and the work would grow like n2n^{2}n2 (standard results, not derived in the notes).
  • Merging streams of arrival times from the arrival-time recursion and sorting them gives the arrival times A1≤A2≤⋯A_1\leq A_2\leq\cdotsA1​≤A2​≤⋯ seen by a common server, and Xj=Aj−Aj−1X_j=A_j-A_{j-1}Xj​=Aj​−Aj−1​ are its inter-arrival times (Alg. 1.4.2).

4. In Python.

import random

def qsort(S):
    if len(S) <= 1:
        return S
    p = random.choice(S)              # ChoosePivot
    L = [x for x in S if x < p]
    M = [x for x in S if x == p]
    R = [x for x in S if x > p]
    return qsort(L) + M + qsort(R)

print(qsort([5, 2, 8, 2, 9, 1]))      # [1, 2, 2, 5, 8, 9]
