Finite Calling Population¶

Definition¶

A queue with a finite calling population draws its jobs from a fixed set of NNN sources. The standard example is a repair shop: a factory has NNN machines and ccc mechanics. A machine is either working or failed; a failed machine waits at the repair department until a mechanic is free and is then repaired. Each working machine fails at rate λ\lambdaλ, independently of the others, and a repair takes an Exp⁡(μ)\operatorname{Exp}(\mu)Exp(μ) time.

Let L(t)L(t)L(t) be the number of machines in repair (waiting or being repaired). When L(t)=nL(t)=nL(t)=n, there are N−nN-nN−n machines running, so in the state-dependent M(n)/M(n)/1M(n)/M(n)/1M(n)/M(n)/1 description

λ(n)=λ(N−n),μ(n)=μmin⁡{n,c},n=0,1,…,N.\lambda(n)=\lambda(N-n),\qquad \mu(n)=\mu\min\{n,c\},\qquad n=0,1,\dots,N.λ(n)=λ(N−n),μ(n)=μmin{n,c},n=0,1,…,N.

Every failed machine enters the repair shop, so λ+(n)=λ(n)\lambda^{+}(n)=\lambda(n)λ+(n)=λ(n), and the state space is {0,1,…,N}\{0,1,\dots,N\}{0,1,…,N}.

Interpretation¶

The input is generated by the population itself: every machine that is in repair is one machine less that can fail. Hence the more crowded the repair shop, the slower new jobs arrive. As L(t)≤NL(t)\le NL(t)≤N, the model is stable for all λ\lambdaλ, μ\muμ and ccc.

Equating the flows across each cut gives the level-crossing equation λ(N−n)p(n)=μ(n+1)p(n+1)\lambda(N-n)p(n)=\mu(n+1)p(n+1)λ(N−n)p(n)=μ(n+1)p(n+1), whose solution is printed under the states.

The rate λ(N−n)\lambda(N-n)λ(N−n) holds because the first failure among N−nN-nN−n running machines is the minimum of independent exponentials. Without exponential times, the state nnn would not determine the rates and the birth-death recursion would not apply.

Because λ(n)\lambda(n)λ(n) depends on nnn, failures do not form a Poisson process and PASTA does not hold: a failing machine tends to find a shorter repair queue than the time average, since failures are rare when many machines are down. When c=Nc=Nc=N the machines alternate independently between working and repair, and LLL has a binomial distribution. When NNN is large and each source rarely calls, λ(N−n)\lambda(N-n)λ(N−n) hardly changes with nnn, which is why a call centre with many potential callers is modelled with Poisson arrivals.

A common slip is to use NλN\lambdaNλ, the failure rate of a fully working factory, in Little's law; the actual failure rate is the smaller λˉ=λ(N−E[L])\bar\lambda=\lambda(N-\mathbb{E}[L])λˉ=λ(N−E[L]).
