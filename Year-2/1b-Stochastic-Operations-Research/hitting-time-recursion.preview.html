Hitting-Time Recursion¶

Method¶

A hitting-time recursion computes the expected time until a process first enters a given hitting set (or stopping set) by conditioning on its first step:

expected time from x=expected duration of one step+E[expected time from the next state],\text{expected time from }x=\text{expected duration of one step}+\mathbb{E}[\text{expected time from the next state}],expected time from x=expected duration of one step+E[expected time from the next state],

with time 000 on the hitting set itself.

For the inventory position under an (s,S)(s,S)(s,S) policy, the position xxx falls by the period demand DDD, with fk=P(D=k)f_k=\mathbb{P}(D=k)fk​=P(D=k), and the hitting set is {x ⁣:x≤s}\{x\colon x\leq s\}{x:x≤s}. The expected number of periods T(s,x)T(s,x)T(s,x) until the position enters it satisfies

T(s,x)={1+E[T(s,x−D)],x>s,0,x≤s.T(s,x)=\begin{cases}1+\mathbb{E}[T(s,x-D)], & x>s,\\ 0, & x\leq s.\end{cases}T(s,x)={1+E[T(s,x−D)],0,​x>s,x≤s.​

Interpretation¶

The question "how long until the process gets there?" is answered by asking a smaller one: where will the process be after one step, and how long does it take from there? After one step the problem looks the same, only from a new state, because the next demand does not depend on the past. The recursion is a law of total expectation over the first step.

From position 111 every positive demand stops the process; from 222 a demand of one leads to 111 and a demand of two stops it. The self-loops are the periods without demand, and they are why each value is divided by 1−f0=341-f_0=\frac{3}{4}1−f0​=43​.

The recursion needs a step law that depends only on the current state (iid demands here, Poisson arrivals in a queue), and the hitting set must be reached in finite expected time: f0<1f_0<1f0​<1 for inventory, ρ<1\rho<1ρ<1 for the NNN-policy queue. The same in Python, in the style of the notes:

from functools import cache

f = {0: 1/4, 1: 1/2, 2: 1/4}   # demand pmf
s = 0

@cache
def T(x):
    if x <= s:                  # in the hitting set
        return 0
    rest = sum(p * T(x - d) for d, p in f.items() if d > 0)
    return (1 + rest) / (1 - f[0])

print(T(2))                     # 2.2222...
