Closure¶

Definition¶

A closure is an inner function, returned by an outer function, that retains the values of variables from the outer call. The scope of a variable is the part of a program in which it can be used; the inner function is created inside the scope of the outer call and keeps access to those variables after the outer call has finished. For example,

power⁡(e) returns b↦be,\operatorname{power}(e)\ \text{returns}\ b\mapsto b^{e},power(e) returns b↦be,

so power⁡(2)\operatorname{power}(2)power(2) is a lambda function b↦b2b\mapsto b^{2}b↦b2 in which the exponent e=2e=2e=2 is fixed. Calling the outer function and naming its output specializes a general template.

Interpretation¶

A closure is a function that comes with its own memory: the outer call sets some parameters once, and the returned function uses them every time it is called, without the caller passing them again.

In the figure one template produces two functions with the same structure. The orange tags are the retained values: the call with e=2e=2e=2 yields square⁡\operatorname{square}square, the call with e=3e=3e=3 yields cube⁡\operatorname{cube}cube, and each keeps its own eee. The green results are the calls square⁡(5)=25\operatorname{square}(5)=25square(5)=25 and cube⁡(4)=64\operatorname{cube}(4)=64cube(4)=64 of Example 1.

Two facts govern how closures behave. Each call of the outer function creates fresh variables, so two maps made by Map⁡()\operatorname{Map}()Map() have separate stores; but functions created in the same call share them, which is how the membership test of a cache sees every value stored in it. And the retained values are those of the outer call that created the closure, so a closure answers with its own parameters, not with whatever a variable of the same name means elsewhere.

In mathematics this is the familiar step from a family of functions to one member: fixing eee in beb^{e}be, or fixing a pmf and getting its cdf as a function of xxx. A frequent slip is to read the inner argument as the outer one, as in Example 2. Later in the course closures return hitting-value and cost functions of inventory policies.
