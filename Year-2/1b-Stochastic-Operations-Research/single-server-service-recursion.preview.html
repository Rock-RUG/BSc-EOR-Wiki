Single-Server Service Recursion¶

Method¶

Consider a single server that serves jobs one at a time in their order of arrival (first in, first out, FIFO) and never stays idle while a job is present. Job k=1,2,…k=1,2,\ldotsk=1,2,… arrives at the epoch AkA_kAk​, with A1≤A2≤⋯A_1\leq A_2\leq\cdotsA1​≤A2​≤⋯, and needs the service time SkS_kSk​. Interpretation¶

The service of job kkk can start only when two things have happened: the job has arrived, and the server has finished job k−1k-1k−1. The start is the later of these two moments, hence the maximum.

Each row of the figure is one job of Example 2. The dot marks the arrival AkA_kAk​, the dashed stretch is the wait and the red bar is the service, which ends at DkD_kDk​. A dotted line drops from the end of each bar to the next row: when it lies to the right of the next arrival dot (jobs 2, 3 and 5), the next job waits until Dk−1D_{k-1}Dk−1​; when it lies to the left (job 4), the server has gone idle and the job starts at its own arrival.

Both assumptions enter through Dk−1D_{k-1}Dk−1​. Under FIFO the job served just before job kkk is job k−1k-1k−1, so its departure is the only one that matters. With c>1c>1c>1 servers, job kkk may start as soon as any server is free, and the recursion must track the work at every server instead. A server that could idle while jobs are waiting would break the maximum as well.

The recursion is the continuous-time version of the discrete-time queue recursion: instead of counting jobs per period, it follows each job individually. A common slip is to write Dk=Dk−1+SkD_k=D_{k-1}+S_kDk​=Dk−1​+Sk​, which is right only when job kkk finds the server busy, or Dk=Ak+SkD_k=A_k+S_kDk​=Ak​+Sk​, which is right only when it finds the system empty. The maximum covers both cases.

3. The recursion in Python. In the style of Algorithm 3.3.1:

def queue_sample_path(x, s):
    A, D = [0], [0]          # A_0 = D_0 = 0 only start the recursions
    W, J = [], []
    for xk, sk in zip(x, s):
        A.append(A[-1] + xk)
        D.append(max(A[-1], D[-1]) + sk)
        J.append(D[-1] - A[-1])
        W.append(J[-1] - sk)
    return A[1:], D[1:], W, J

A, D, W, J = queue_sample_path([1, 1, 3, 4, 1], [3, 2, 1, 2, 2])
# D == [4, 6, 7, 11, 13] and W == [0, 2, 1, 0, 1]
