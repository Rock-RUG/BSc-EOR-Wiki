N-Policy¶

Definition¶

Consider an M/G/1M/G/1M/G/1 queue: jobs arrive as a Poisson process with rate λ\lambdaλ, service times SSS are iid with finite E[S]\mathbb{E}[S]E[S] and E[S2]\mathbb{E}[S^2]E[S2], there is one server, and the load ρ=λE[S]<1\rho=\lambda\mathbb{E}[S]<1ρ=λE[S]<1. Under an NNN-policy with integer threshold N≥1N\geq1N≥1, the server switches off as soon as the system becomes empty and stays off until NNN jobs are present; it then switches on and serves until the system is empty again.

Each switch-on costs a setup cost K≥0K\geq0K≥0, and every job in the system costs hhh per unit of time. A cycle starts when the server switches off. It consists of a build-up phase, in which NNN inter-arrival times pass, and a clearing phase, which lasts T(N)T(N)T(N), where T(q)T(q)T(q) denotes the expected time to empty the system once the server starts on the first of qqq jobs present. The expected cycle length is therefore

C(N)=Nλ+T(N).C(N)=\frac{N}{\lambda}+T(N).C(N)=λN​+T(N).

Interpretation¶

An NNN-policy lets work pile up on purpose. Starting the server is expensive, so the server waits until a batch of NNN jobs is ready and then clears them in one run; a larger NNN means fewer setups per hour but longer queues.

While the server is off, L(t)L(t)L(t) only rises; at the fourth arrival, time 444, the server switches on, and L(t)L(t)L(t) drops at a departure every half hour and rises at three more arrivals until the system empties at time 7.57.57.5. The expected phases are N/λ=4N/\lambda=4N/λ=4 and T(4)=4T(4)=4T(4)=4 hours, and the waiting cost of a cycle is hhh times the area under the path.

The clearing time follows from a first-step argument: with YYY the number of arrivals during one service, T(q)=E[S]+E[T(q+Y−1)]T(q)=\mathbb{E}[S]+\mathbb{E}[T(q+Y-1)]T(q)=E[S]+E[T(q+Y−1)] and T(0)=0T(0)=0T(0)=0. Since E[Y]=λE[S]\mathbb{E}[Y]=\lambda\mathbb{E}[S]E[Y]=λE[S] by Adam's law, the solution is qqq mean busy periods. It is finite only because ρ<1\rho<1ρ<1; then the queue is rate stable for every NNN, and the utilization stays ρ\rhoρ, because NNN changes when work is done, not how much. Dividing the expected cycle cost by C(N)C(N)C(N) is the renewal reward theorem.

With N=1N=1N=1 and K=0K=0K=0 the cost with h=1h=1h=1 is E[L]\mathbb{E}[L]E[L] of the Pollaczek–Khinchine formula, and N∗N^*N∗ has the square-root form of the EOQ and EPQ formulas.
