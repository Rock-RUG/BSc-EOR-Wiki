Interpretation¶

The recursion follows the position through one replenishment cycle, as in the (T,S)(T,S)(T,S) case, but the cycle now ends when the position enters the stopping set {x≤s}\{x\leq s\}{x≤s} instead of when a clock runs out. A period without demand leaves the position where it was, so the recursion refers to itself. Isolating that self-term is the whole trick.

The figure shows Example 1 with s=0s=0s=0 and S=2S=2S=2. Each self-loop is a period of zero demand, probability f0=14f_0=\tfrac{1}{4}f0​=41​; the other arrows lower the position by 111 or 222. This explains the formula: the number of periods the position stays at xxx has the first success distribution with success probability 1−f01-f_01−f0​ and mean 1/(1−f0)=431/(1-f_0)=\tfrac{4}{3}1/(1−f0​)=34​, each costing L(x)L(x)L(x), and then moves to x−kx-kx−k with probability fk/(1−f0)f_k/(1-f_0)fk​/(1−f0​). All other arrows point to lower positions, so the values follow upwards from the stopping set: V(s,1)=233V(s,1)=\tfrac{23}{3}V(s,1)=323​, then V(s,2)=769V(s,2)=\tfrac{76}{9}V(s,2)=976​.

The condition f0<1f_0<1f0​<1 only excludes the case without demand. The method needs non-negative demand, so that positions never move up during a cycle. The stopping set is {x≤s}\{x\leq s\}{x≤s}, not the single level sss: with P(D≥2)>0\mathbb{P}(D\geq2)>0P(D≥2)>0 the position can jump past sss (TF 5.9.2).

This overshoot, together with the non-linear (but convex) LLL, is why no closed form like the N-policy result T(q)=q/(μ−λ)T(q)=q/(\mu-\lambda)T(q)=q/(μ−λ) exists here: that queue moves down one step at a time, so a linear guess αq+β\alpha q+\betaαq+β solves its recursion, while here it does not. Called with (L,K)(L,K)(L,K) and with (1,0)(1,0)(1,0), one function gives cycle cost and cycle length; their ratio is the renewal reward theorem, and memoization keeps it fast.

4. Implementation. Following the notes' sSHittingValue, the function below returns a closure VVV that caches its values:

from functools import cache

def ss_hitting_value(p_D, R, H):
    positive = [d for d in p_D if d > 0]

    @cache
    def V(s, x):
        if x <= s:
            return H(x)
        z = sum(p_D[d] * V(s, x - d) for d in positive)
        return (R(x) + z) / (1 - p_D.get(0, 0))
    return V

V = ss_hitting_value(p_D, L, lambda x: K)
tau = ss_hitting_value(p_D, lambda x: 1, lambda x: 0)
