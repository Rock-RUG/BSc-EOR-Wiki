Interpretation¶

The service rate is the capacity of the server: the number of jobs per unit time it would complete if it never stood idle. It is a property of the server and the jobs' work, not of the arrivals, and it is an upper bound for the departure rate δ\deltaδ that the server actually achieves.

The dashed staircase U(t)U(t)U(t) is what a server with service time 1.51.51.5 could do if jobs were always waiting: one completion every 1.51.51.5 time units, so μ=23\mu=\frac{2}{3}μ=32​. The solid staircase D(t)D(t)D(t) counts the jobs that really leave. Because only one job arrives every two time units on average, the server is idle part of the time, and D(t)D(t)D(t) grows at the smaller slope δ=12\delta=\frac{1}{2}δ=21​: by t=12t=12t=12 the server could have completed 888 jobs but has completed 555.

The relation μ=1/E[S]\mu=1/\mathbb{E}[S]μ=1/E[S] follows from the same counting argument as λ=1/E[X]\lambda=1/\mathbb{E}[X]λ=1/E[X] for arrivals. The bound δ≤μ\delta\leq\muδ≤μ holds for any single server, since each departure uses up one service time. Equality in an overloaded queue needs a work-conserving server (Kendall's convention), which never idles while jobs are present.

For an exponential service time S∼Exp⁡(μ)S\sim\operatorname{Exp}(\mu)S∼Exp(μ), the letter MMM in Kendall's notation, μ\muμ is the rate parameter of the exponential distribution. In the discrete-time models of Week 2 the same role is played by the mean capacity per period, μ=E[ck]\mu=\mathbb{E}[c_k]μ=E[ck​], which decides the sign of the queue drift.

A common slip is to call the observed output rate the service rate. A server that is idle a quarter of the time has δ<μ\delta<\muδ<μ; only in an overloaded queue without blocking does the output reach μ\muμ.
