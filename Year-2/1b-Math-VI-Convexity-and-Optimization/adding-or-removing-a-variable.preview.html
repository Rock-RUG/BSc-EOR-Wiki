Adding or Removing a Variable¶

Method¶

Input: a linear program in standard form max⁡Z=c⊤x\max Z=\boldsymbol{c}^{\top}\boldsymbol{x}maxZ=c⊤x subject to Ax≤b\boldsymbol{A}\boldsymbol{x}\leq\boldsymbol{b}Ax≤b, x≥0\boldsymbol{x}\geq\boldsymbol{0}x≥0, its final tableau for an optimal basis B∗\mathcal{B}^*B∗ (the set of basic indices, with N∗\mathcal{N}^*N∗ the nonbasic ones) with basis matrix B\boldsymbol{B}B, cost vector cB\boldsymbol{c}_{\mathcal{B}}cB​, optimal solution x∗\boldsymbol{x}^*x∗ and dual solution y∗⊤=cB⊤B−1\boldsymbol{y}^{*\top}=\boldsymbol{c}_{\mathcal{B}}^{\top}\boldsymbol{B}^{-1}y∗⊤=cB⊤​B−1. The constraints stay the same; only one variable xj′x_{j'}xj′​ is removed or added.

Removing a variable xj′x_{j'}xj′​:

  1. If xj′x_{j'}xj′​ is nonbasic (j′∈j′∈N∗j'\in\mathcal{N}^*N∗), nothing changes: B∗\mathcal{B}^*B∗ is still an optimal basis and x∗\boldsymbol{x}^*x∗, without its j′j'j′-th entry, is still optimal.
  2. If xj′x_{j'}xj′​ is basic (j′∈j′∈B∗j'\in\mathcal{B}^*B∗), only m−1m-1m−1 of the mmm columns of B\boldsymbol{B}B are left, so B∗\mathcal{B}^*B∗ is no longer a basis. The solution x∗\boldsymbol{x}^*x∗ stays feasible only if xj′∗=0x_{j'}^*=0xj′∗​=0, which means B∗\mathcal{B}^*B∗ is degenerate. In that case x∗\boldsymbol{x}^*x∗ is still optimal, because removing a variable cannot raise the optimal value. If xj′∗>0x_{j'}^*>0xj′∗​>0, the linear program without xj′x_{j'}xj′​ is solved again.

Adding an original (non-slack) variable xj′x_{j'}xj′​ with objective coefficient cj′c_{j'}cj′​ and column Aj′∈Rm\boldsymbol{A}_{j'}\in\mathbb{R}^mAj′​∈Rm:

  1. Add xj′x_{j'}xj′​ as a nonbasic variable. The right-hand side and the basic values do not change, so B∗\mathcal{B}^*B∗ remains feasible and x∗\boldsymbol{x}^*x∗ with xj′=0x_{j'}=0xj′​=0 remains a feasible solution.

  2. Compute its reduced cost

    cˉj′=−cj′+cB⊤B−1Aj′=−cj′+y∗⊤Aj′.\bar{c}_{j'}=-c_{j'}+\boldsymbol{c}_{\mathcal{B}}^{\top}\boldsymbol{B}^{-1}\boldsymbol{A}_{j'}=-c_{j'}+\boldsymbol{y}^{*\top}\boldsymbol{A}_{j'}.cˉj′​=−cj′​+cB⊤​B−1Aj′​=−cj′​+y∗⊤Aj′​.

  3. If cˉj′≥0\bar{c}_{j'}\geq0cˉj′​≥0, B∗\mathcal{B}^*B∗ and x∗\boldsymbol{x}^*x∗ (with xj′=0x_{j'}=0xj′​=0) remain optimal.

  4. If cˉj′<0\bar{c}_{j'}<0cˉj′​<0, add the column B−1Aj′\boldsymbol{B}^{-1}\boldsymbol{A}_{j'}B−1Aj′​ with objective entry cˉj′\bar{c}_{j'}cˉj′​ to the final tableau and continue the revised simplex algorithm with xj′x_{j'}xj′​ entering.

Interpretation¶

Adding a variable means offering the model a new activity, for example a new product, without new constraints. Since it enters with value 000, the current plan stays feasible; the only question is whether the new activity pays.

The figure shows Example 1 below. One unit of the third product uses the column A3=(1,2,1)⊤\boldsymbol{A}_3=(1,2,1)^{\top}A3​=(1,2,1)⊤, which at the shadow prices y∗=(0,32,1)⊤\boldsymbol{y}^*=(0,\tfrac{3}{2},1)^{\top}y∗=(0,23​,1)⊤ is worth 0⋅1+32⋅2+1⋅1=40\cdot1+\tfrac{3}{2}\cdot2+1\cdot1=40⋅1+23​⋅2+1⋅1=4 (red bar; the first resource costs nothing, as y1∗=0y_1^*=0y1∗​=0). The reduced cost cˉ3=4−c3\bar{c}_3=4-c_3cˉ3​=4−c3​ is the gap between this value and the price: for c3=3c_3=3c3​=3 it is 1≥01\geq01≥0, so the basis stays optimal and the product is not made; for c3=6c_3=6c3​=6 it is −2-2−2, so x3x_3x3​ enters and the optimal value rises to 393939 (Example 2 below). The threshold is c3=4c_3=4c3​=4, where the price just covers the value of the resources.

The reduced cost answers this by pricing it at the current shadow prices: y∗⊤Aj′\boldsymbol{y}^{*\top}\boldsymbol{A}_{j'}y∗⊤Aj′​ is what the resources for one unit are worth in the current plan, and the product is worth producing only if it earns more than that, cj′>y∗⊤Aj′c_{j'}>\boldsymbol{y}^{*\top}\boldsymbol{A}_{j'}cj′​>y∗⊤Aj′​. In dual terms, the new variable adds the constraint Aj′⊤y≥cj′\boldsymbol{A}_{j'}^{\top}\boldsymbol{y}\geq c_{j'}Aj′⊤​y≥cj′​, and cˉj′≥0\bar{c}_{j'}\geq0cˉj′​≥0 says that y∗\boldsymbol{y}^*y∗ still satisfies it.

Removing a variable is the same as forcing it to be 000. The feasible region can only shrink, so the optimal value cannot rise. A nonbasic variable is already 000, so nothing happens. A basic one leaves a hole in B\boldsymbol{B}B; if its value was positive, the remaining variables must readjust, and the optimal value may drop (Example 3 below).

This is the computation behind the reduced cost of an unused product in OR Modelling, where the reported number is −cˉj′-\bar{c}_{j'}−cˉj′​, and it is a technology coefficient change applied to a whole column.

A common slip is to think that a positive profit cj′>0c_{j'}>0cj′​>0 makes a new product worth adding. In Example 1 below the product earns 333 per unit and is still not produced, because the resources it needs are worth 444 in the current plan.

Key Results¶

  • Removing a nonbasic variable changes neither B∗\mathcal{B}^*B∗ nor x∗\boldsymbol{x}^*x∗, and both remain optimal.
  • Removing a basic variable destroys the basis B∗\mathcal{B}^*B∗; x∗\boldsymbol{x}^*x∗ stays feasible only if the removed variable has value 000 in it, that is, B∗\mathcal{B}^*B∗ is degenerate, and then x∗\boldsymbol{x}^*x∗ is still optimal.
  • A new original variable can always be added as a nonbasic variable, and B∗\mathcal{B}^*B∗ remains feasible.
  • B∗\mathcal{B}^*B∗ and x∗\boldsymbol{x}^*x∗ remain optimal as long as −cj′+cB⊤B−1Aj′≥0-c_{j'}+\boldsymbol{c}_{\mathcal{B}}^{\top}\boldsymbol{B}^{-1}\boldsymbol{A}_{j'}\geq0−cj′​+cB⊤​B−1Aj′​≥0; otherwise xj′x_{j'}xj′​ can enter in the next simplex iteration (Example 2 below).
