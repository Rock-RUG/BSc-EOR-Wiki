Hypograph¶

Definition¶

Let D⊆RnD\subseteq\mathbb{R}^nD⊆Rn and let f ⁣:D→Rf\colon D\to\mathbb{R}f:D→R. The hypograph of fff is the subset of Rn+1\mathbb{R}^{n+1}Rn+1

Hypo⁡(f)={(x,y)∈Rn×R ⁣:x∈D, y≤f(x)}.\operatorname{Hypo}(f)=\{(\boldsymbol{x},y)\in\mathbb{R}^n\times\mathbb{R}\colon \boldsymbol{x}\in D,\ y\leq f(\boldsymbol{x})\}.Hypo(f)={(x,y)∈Rn×R:x∈D, y≤f(x)}.

It consists of the points of the graph of fff and all points below them. When DDD is convex, fff is a concave function if and only if Hypo⁡(f)\operatorname{Hypo}(f)Hypo(f) is a convex set.

Interpretation¶

The hypograph is everything on or below the graph. It is the mirror image of the epigraph and does for concave functions what the epigraph does for convex ones.

On the left, the shaded set is the hypograph of the concave upper semicircle f(x)=1−x2f(x)=\sqrt{1-x^2}f(x)=1−x2​ of Example 4 below: the strip under the arc between x=−1x=-1x=−1 and x=1x=1x=1, continuing downward without bound. It is convex. On the right is Example 2 below: the hypograph of the convex function x2x^2x2 contains (−1,1)(-1,1)(−1,1) and (1,1)(1,1)(1,1) but not their midpoint (0,1)(0,1)(0,1), the open circle, because f(0)=0<1f(0)=0<1f(0)=0<1. So Hypo⁡(x2)\operatorname{Hypo}(x^2)Hypo(x2) is not convex and x2x^2x2 is not concave.

The mirror can be made exact. A point (x,y)(\boldsymbol{x},y)(x,y) lies in Hypo⁡(f)\operatorname{Hypo}(f)Hypo(f) exactly when (x,−y)(\boldsymbol{x},-y)(x,−y) lies in Epi⁡(−f)\operatorname{Epi}(-f)Epi(−f), because y≤f(x)y\leq f(\boldsymbol{x})y≤f(x) is the same as −y≥−f(x)-y\geq-f(\boldsymbol{x})−y≥−f(x). Flipping the last coordinate is a linear map that sends segments to segments, so Hypo⁡(f)\operatorname{Hypo}(f)Hypo(f) is convex exactly when Epi⁡(−f)\operatorname{Epi}(-f)Epi(−f) is. Since a function on a convex set is convex exactly when its epigraph is convex, this happens exactly when −f-f−f is convex, which is the definition of fff being concave. This proves the hypograph criterion for concavity.

Epigraph and hypograph together give the graph: Epi⁡(f)∩Hypo⁡(f)\operatorname{Epi}(f)\cap\operatorname{Hypo}(f)Epi(f)∩Hypo(f) is the set of points with y=f(x)y=f(\boldsymbol{x})y=f(x). If fff is both convex and concave, as an affine function is, both sets are convex and so is their intersection, the graph. For an affine function on Rn\mathbb{R}^nRn the two sets are closed halfspaces in Rn+1\mathbb{R}^{n+1}Rn+1 and the graph is a hyperplane. For most functions the graph is not convex.

A common slip is to expect a concave function to have a convex epigraph as well. Only the hypograph is convex; for a concave function that is not convex, the epigraph is not convex. Horizontal slices of the hypograph are superlevel sets, the starting point for quasi-concave functions.

Key Results¶

  • Let D⊆RnD\subseteq\mathbb{R}^nD⊆Rn be convex and f ⁣:D→Rf\colon D\to\mathbb{R}f:D→R. Then fff is concave if and only if Hypo⁡(f)\operatorname{Hypo}(f)Hypo(f) is convex.
  • (x,y)∈Hypo⁡(f)(\boldsymbol{x},y)\in\operatorname{Hypo}(f)(x,y)∈Hypo(f) if and only if (x,−y)∈Epi⁡(−f)(\boldsymbol{x},-y)\in\operatorname{Epi}(-f)(x,−y)∈Epi(−f).
  • The graph of fff is Epi⁡(f)∩Hypo⁡(f)\operatorname{Epi}(f)\cap\operatorname{Hypo}(f)Epi(f)∩Hypo(f). On a convex set DDD it is convex if and only if fff is both convex and concave: for two points of the graph, the convex combination lies on the graph exactly when the defining inequalities of convexity and concavity both hold.
  • For every α∈R\alpha\in\mathbb{R}α∈R, the superlevel set {x∈D ⁣:f(x)≥α}\{\boldsymbol{x}\in D\colon f(\boldsymbol{x})\geq\alpha\}{x∈D:f(x)≥α} equals {x ⁣:(x,α)∈Hypo⁡(f)}\{\boldsymbol{x}\colon(\boldsymbol{x},\alpha)\in\operatorname{Hypo}(f)\}{x:(x,α)∈Hypo(f)}.

1. Under a paraboloid. Let g(x)=1−x12−x22g(\boldsymbol{x})=1-x_1^2-x_2^2g(x)=1−x12​−x22​ on R2\mathbb{R}^2R2. 2. A convex function has a nonconvex hypograph. For f(x)=x2f(x)=x^2f(x)=x2, the points (−1,1)(-1,1)(−1,1) and (1,1)(1,1)(1,1) lie on the graph, hence in Hypo⁡(f)\operatorname{Hypo}(f)Hypo(f). The same midpoint lies in Epi⁡(f)\operatorname{Epi}(f)Epi(f) but not on the graph, so the graph of x2x^2x2 is not convex either.

3. An affine function. For f(x)=2x1−x2+3f(\boldsymbol{x})=2x_1-x_2+3f(x)=2x1​−x2​+3 on R2\mathbb{R}^2R2,
