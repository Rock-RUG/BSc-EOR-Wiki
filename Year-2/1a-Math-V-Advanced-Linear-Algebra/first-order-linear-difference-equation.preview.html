First-Order Linear Difference Equation¶

Definition¶

A first-order linear difference equation with constant coefficient is

xt+1=a xt+gt,t=0,1,2,…,x_{t+1}=a\,x_t+g_t,\qquad t=0,1,2,\ldots,xt+1​=axt​+gt​,t=0,1,2,…,

where a≠0a\ne0a=0 is a real constant and (gt)t≥0(g_t)_{t\ge0}(gt​)t≥0​ is a given forcing sequence. It is homogeneous if gt=0g_t=0gt​=0 for all ttt. For every initial value x0x_0x0​ the unique solution is

xt=atx0+∑s=0t−1a t−1−s gs.x_t=a^t x_0+\sum_{s=0}^{t-1}a^{\,t-1-s}\,g_s.xt​=atx0​+s=0∑t−1​at−1−sgs​.

Interpretation¶

The next state is the current state scaled by aaa plus an external input. The solution formula is obtained by substituting the equation into itself: the initial value is multiplied by aaa once per period, and the input gsg_sgs​ received at time sss has been multiplied by aaa for the remaining t−1−st-1-st−1−s periods.
