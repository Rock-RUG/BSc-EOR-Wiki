Similarity Transformation¶

Definition¶

Let AAA and BBB be real n×nn\times nn×n matrices. BBB is similar to AAA, written A∼BA\sim BA∼B, if there is an invertible n×nn\times nn×n matrix PPP with

B=P−1AP.B=P^{-1}AP.B=P−1AP.

The map A↦P−1APA\mapsto P^{-1}APA↦P−1AP is a similarity transformation. Some texts write PAP−1PAP^{-1}PAP−1 instead; this only replaces PPP by P−1P^{-1}P−1.

Interpretation¶

Similar matrices represent the same linear operator in different bases. If the columns of PPP form a basis B\mathcal{B}B and AAA is the matrix in standard coordinates, then P−1APP^{-1}APP−1AP is the matrix in B\mathcal{B}B-coordinates: convert to standard coordinates (PPP), apply AAA, convert back (P−1P^{-1}P−1). Here PPP is the transformation matrix of B\mathcal{B}B, written FFF on the change of basis page.

The square uses the diagonalization example below. Going up with PPP, across with AAA and down with P−1P^{-1}P−1 gives the same result as going across the bottom with BBB; this is the identity B=P−1APB=P^{-1}APB=P−1AP. Both rows describe one operator, so its eigenvalues 555 and 222 appear in both: as the roots of the characteristic polynomial of AAA and as the diagonal entries of BBB.

Everything that describes the operator itself, rather than its coordinates, is therefore unchanged by similarity: eigenvalues, determinant, trace, rank. Eigenvectors are not invariant; they change coordinates along with everything else.

Two misconceptions. Equal invariants do not prove similarity (see the example below). And similarity is not row equivalence: EAEAEA for an invertible EEE generally has different eigenvalues from AAA.

Key Results¶

  • Similarity is an equivalence relation on n×nn\times nn×n matrices.
  • Similar matrices have the same characteristic polynomial, hence the same eigenvalues with the same algebraic multiplicities; geometric multiplicities, determinant, trace and rank also agree.
  • If Av=λvA\boldsymbol{v}=\lambda\boldsymbol{v}Av=λv and B=P−1APB=P^{-1}APB=P−1AP, then B(P−1v)=λ P−1vB(P^{-1}\boldsymbol{v})=\lambda\,P^{-1}\boldsymbol{v}B(P−1v)=λP−1v.
  • Bk=P−1AkPB^k=P^{-1}A^kPBk=P−1AkP for all k≥0k\ge0k≥0, and more generally p(B)=P−1p(A)Pp(B)=P^{-1}p(A)Pp(B)=P−1p(A)P for polynomials ppp; likewise eBt=P−1eAtP\mathrm{e}^{Bt}=P^{-1}\mathrm{e}^{At}PeBt=P−1eAtP for the matrix exponential.
  • AAA is diagonalizable if and only if it is similar to a diagonal matrix. Over C\mathbb{C}C, two matrices are similar if and only if they have the same Jordan normal form up to the order of the blocks.
  • A real symmetric matrix is orthogonally similar to a diagonal matrix: Q⊤AQ=ΛQ^{\top}AQ=\LambdaQ⊤AQ=Λ with Q⊤=Q−1Q^{\top}=Q^{-1}Q⊤=Q−1.
