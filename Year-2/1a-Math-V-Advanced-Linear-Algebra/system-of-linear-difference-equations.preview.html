System of Linear Difference Equations¶

Definition¶

A system of linear difference equations (first order, constant coefficients) is

xt+1=Axt+bt,t=0,1,2,…,\boldsymbol{x}_{t+1}=A\boldsymbol{x}_t+\boldsymbol{b}_t,\qquad t=0,1,2,\ldots,xt+1​=Axt​+bt​,t=0,1,2,…,

where xt∈Rn\boldsymbol{x}_t\in\mathbb{R}^nxt​∈Rn is the state vector, AAA is a fixed real n×nn\times nn×n matrix and (bt)(\boldsymbol{b}_t)(bt​) is a given sequence of forcing vectors. It is homogeneous if bt=0\boldsymbol{b}_t=\boldsymbol{0}bt​=0 for all ttt. For every initial vector x0\boldsymbol{x}_0x0​ the unique solution is

xt=Atx0+∑s=0t−1At−1−sbs.\boldsymbol{x}_t=A^t\boldsymbol{x}_0+\sum_{s=0}^{t-1}A^{t-1-s}\boldsymbol{b}_s.xt​=Atx0​+s=0∑t−1​At−1−sbs​.

Interpretation¶

Entry aija_{ij}aij​ says how much variable jjj today contributes to variable iii in the next period. The system is the vector form of the first-order linear difference equation: the number aaa becomes the matrix AAA, and ata^tat becomes the matrix power AtA^tAt.

Writing x0=(1,0)⊤\boldsymbol{x}_0=(1,0)^{\top}x0​=(1,0)⊤ in the eigenvector basis, the component along (2,1)⊤(2,1)^{\top}(2,1)⊤ (λ=1\lambda=1λ=1) never changes, while the component along (1,−1)⊤(1,-1)^{\top}(1,−1)⊤ (λ=0.7\lambda=0.7λ=0.7) is multiplied by 0.70.70.7 each period. So the iterates move along the dashed line through x0\boldsymbol{x}_0x0​ in direction (1,−1)⊤(1,-1)^{\top}(1,−1)⊤, with steps shrinking by the factor 0.70.70.7, towards x∗=(2/3,1/3)⊤\boldsymbol{x}^*=(2/3,1/3)^{\top}x∗=(2/3,1/3)⊤ on the blue eigenvector line.

Powers of AAA are hard to read off directly, which is where eigenvalues and eigenvectors come in. If Ap=λpA\boldsymbol{p}=\lambda\boldsymbol{p}Ap=λp, then Atp=λtpA^t\boldsymbol{p}=\lambda^t\boldsymbol{p}Atp=λtp: along an eigenvector the system behaves like a scalar equation. When AAA has nnn independent eigenvectors, write x0\boldsymbol{x}_0x0​ in that basis and each component evolves separately. This is diagonalization applied to dynamics.

Any scalar higher-order equation can be written as such a system with a companion matrix, so the system covers every linear constant-coefficient difference equation. A common mistake is to compute AtA^tAt entrywise, as if (At)ij=aijt(A^t)_{ij}=a_{ij}^t(At)ij​=aijt​; this is only true for diagonal matrices.

Key Results¶

  • If A=PDP−1A=PDP^{-1}A=PDP−1 with D=diag⁡(λ1,…,λn)D=\operatorname{diag}(\lambda_1,\ldots,\lambda_n)D=diag(λ1​,…,λn​), then At=PDtP−1A^t=PD^tP^{-1}At=PDtP−1 and the homogeneous solution is xt=∑i=1nciλitpi\displaystyle \boldsymbol{x}_t=\sum_{i=1}^n c_i\lambda_i^t\boldsymbol{p}_ixt​=i=1∑n​ci​λit​pi​ with c=P−1x0\boldsymbol{c}=P^{-1}\boldsymbol{x}_0c=P−1x0​.
  • For a nondiagonalizable AAA, the Jordan normal form adds terms tjλtt^j\lambda^ttjλt (λ≠0\lambda\ne0λ=0) for 0≤j<0\le j<0≤j< the size of the Jordan block.
  • With constant forcing b\boldsymbol{b}b, an equilibrium solves (I−A)x∗=b(I-A)\boldsymbol{x}^*=\boldsymbol{b}(I−A)x∗=b; it is unique if and only if 111 is not an eigenvalue of AAA. Then xt−x∗=At(x0−x∗)\boldsymbol{x}_t-\boldsymbol{x}^*=A^t(\boldsymbol{x}_0-\boldsymbol{x}^*)xt​−x∗=At(x0​−x∗).
  • Nonreal eigenvalues of the real matrix AAA come in conjugate pairs and produce oscillating real solutions.
  • The long-run behaviour is governed by the eigenvalues of largest modulus; see stability.
