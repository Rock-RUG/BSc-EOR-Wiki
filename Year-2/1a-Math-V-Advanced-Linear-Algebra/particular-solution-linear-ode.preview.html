Particular Solution of an Inhomogeneous Linear ODE¶

Definition¶

Write a linear ordinary differential equation (ODE) of order nnn as L[x]=gL[x]=gL[x]=g, where

L[x]=x(n)+an−1x(n−1)+⋯+a1x′+a0x,L[x]=x^{(n)}+a_{n-1}x^{(n-1)}+\dots +a_1x'+a_0x,L[x]=x(n)+an−1​x(n−1)+⋯+a1​x′+a0​x,

x′(t)=dxdt(t)x'(t)=\dfrac{\mathrm{d}x}{\mathrm{d}t}(t)x′(t)=dtdx​(t), and ggg is a given forcing term with g≢0g\not\equiv0g≡0 (the inhomogeneous case). A particular solution is any one function xpx_pxp​ that satisfies L[xp]=gL[x_p]=gL[xp​]=g on the interval considered. The coefficients may be constants or continuous functions of ttt.

Interpretation¶

The particular solution is the response to the forcing ggg; the solutions of the homogeneous equation L[x]=0L[x]=0L[x]=0 describe the free motion of the system. The word "particular" means "one specific", not "special": xpx_pxp​ is not unique, since adding any homogeneous solution gives another particular solution.

The gap between the two curves is exactly this homogeneous solution; here it dies out, so both curves follow the same forced response for large ttt.

This mirrors linear algebra: for a homogeneous and inhomogeneous system Ax=bA\boldsymbol{x}=\boldsymbol{b}Ax=b, one solution of the inhomogeneous system plus the null space gives all solutions. Here LLL is linear, so the same structure holds; see general solution of a linear ODE.

For first-order equations a particular solution can always be computed with an integrating factor. For constant coefficients and forcing of polynomial, exponential, sine or cosine type, the method of undetermined coefficients is quicker: guess a function of the same type as ggg with unknown coefficients and match terms. If the guess already solves the homogeneous equation (resonance), it must be multiplied by ttt; forgetting this leads to the impossible equation 0=g0=g0=g.
