Singular Value¶

Definition¶

Let AAA be a real m×nm\times nm×n matrix and p=min⁡(m,n)p=\min(m,n)p=min(m,n). The matrix A⊤AA^{\top}AA⊤A is symmetric and positive semidefinite, so its eigenvalues are real and nonnegative; order them λ1≥⋯≥λn≥0\lambda_1\ge\cdots\ge\lambda_n\ge0λ1​≥⋯≥λn​≥0. The singular values of AAA are

σi=λi(i=1,…,p),σ1≥σ2≥⋯≥σp≥0.\sigma_i=\sqrt{\lambda_i}\quad(i=1,\ldots,p),\qquad \sigma_1\ge\sigma_2\ge\cdots\ge\sigma_p\ge0.σi​=λi​​(i=1,…,p),σ1​≥σ2​≥⋯≥σp​≥0.

They are the diagonal entries of Σ\SigmaΣ in the singular value decomposition A=UΣV⊤A=U\Sigma V^{\top}A=UΣV⊤. Some texts list only the positive ones, or all nnn values; the positive singular values are the same under every convention.

Interpretation¶

Singular values measure stretching. A matrix maps the unit sphere onto an ellipsoid whose semi-axis lengths are the singular values: σ1\sigma_1σ1​ is the largest factor by which AAA lengthens a unit vector, and zero singular values mark directions that are collapsed.

The figure uses the first example below, A=(1101)A=\begin{pmatrix}1&1\\0&1\end{pmatrix}A=(10​11​). Both eigenvalues are 111, yet the unit circle is stretched into an ellipse with semi-axes σ1≈1.618\sigma_1\approx1.618σ1​≈1.618 and σ2≈0.618\sigma_2\approx0.618σ2​≈0.618. The blue and red unit vectors on the left are the directions that land on these semi-axes (eigenvectors of A⊤AA^{\top}AA⊤A), and every length ∥Ax∥\|A\boldsymbol{x}\|∥Ax∥ with ∥x∥=1\|\boldsymbol{x}\|=1∥x∥=1 lies between σ2\sigma_2σ2​ and σ1\sigma_1σ1​.

Nonnegativity of λi\lambda_iλi​ comes from x⊤A⊤Ax=∥Ax∥2≥0\boldsymbol{x}^{\top}A^{\top}A\boldsymbol{x}=\|A\boldsymbol{x}\|^2\ge0x⊤A⊤Ax=∥Ax∥2≥0, with ∥⋅∥\|\cdot\|∥⋅∥ the Euclidean norm.

Singular values are not the absolute values of the eigenvalues, except for special matrices such as symmetric ones. They exist for rectangular matrices, are always real and nonnegative, and do not change under orthogonal transformations of either side, whereas eigenvalues can be complex and are defined only for square matrices.

Key Results¶

  • A⊤AA^{\top}AA⊤A and AA⊤AA^{\top}AA⊤ have the same nonzero eigenvalues, so AAA and A⊤A^{\top}A⊤ have the same singular values; either product may be used, whichever is smaller.
  • The number of positive singular values equals the rank of AAA.
  • σ1=max⁡∥x∥=1∥Ax∥\sigma_1=\max_{\|\boldsymbol{x}\|=1}\|A\boldsymbol{x}\|σ1​=max∥x∥=1​∥Ax∥, the spectral (operator) norm ∥A∥2\|A\|_2∥A∥2​. If m≥nm\ge nm≥n, σn=min⁡∥x∥=1∥Ax∥\sigma_n=\min_{\|\boldsymbol{x}\|=1}\|A\boldsymbol{x}\|σn​=min∥x∥=1​∥Ax∥.
  • Via the trace: σ12+⋯+σp2=tr⁡(A⊤A)=∑i,jaij2\displaystyle \sigma_1^2+\cdots+\sigma_p^2=\operatorname{tr}(A^{\top}A)=\sum_{i,j}a_{ij}^2σ12​+⋯+σp2​=tr(A⊤A)=i,j∑​aij2​ (squared Frobenius norm).
  • For square AAA, the determinant satisfies ∣det⁡A∣=σ1⋯σn|\det A|=\sigma_1\cdots\sigma_n∣detA∣=σ1​⋯σn​, so AAA is invertible if and only if σn>0\sigma_n>0σn​>0.
  • Symmetric AAA: σi=∣λi(A)∣\sigma_i=|\lambda_i(A)|σi​=∣λi​(A)∣ after reordering. Orthogonal QQQ: all singular values equal 111. Scaling: the singular values of cAcAcA are ∣c∣σi|c|\sigma_i∣c∣σi​.
