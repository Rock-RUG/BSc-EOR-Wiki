System of Differential Equations¶

Definition¶

A system of differential equations consists of nnn first-order differential equations for nnn unknown functions x1(t),…,xn(t)x_1(t),\dots,x_n(t)x1​(t),…,xn​(t). For i=1,…,ni=1,\dots,ni=1,…,n,

xi′(t)=fi(t,x1(t),…,xn(t)),x_i'(t)=f_i\big(t,x_1(t),\dots,x_n(t)\big),xi′​(t)=fi​(t,x1​(t),…,xn​(t)),

where xi′(t)=dxidt(t)x_i'(t)=\dfrac{\mathrm{d}x_i}{\mathrm{d}t}(t)xi′​(t)=dtdxi​​(t). With the state vector x(t)=(x1(t),…,xn(t))⊤\boldsymbol{x}(t)=\big(x_1(t),\dots,x_n(t)\big)^{\top}x(t)=(x1​(t),…,xn​(t))⊤ it reads x′(t)=f(t,x(t))\boldsymbol{x}'(t)=\boldsymbol{f}\big(t,\boldsymbol{x}(t)\big)x′(t)=f(t,x(t)). The system is linear if

x′(t)=A(t) x(t)+b(t)\boldsymbol{x}'(t)=A(t)\,\boldsymbol{x}(t)+\boldsymbol{b}(t)x′(t)=A(t)x(t)+b(t)

for an n×nn\times nn×n matrix function A(t)A(t)A(t) and a vector function b(t)\boldsymbol{b}(t)b(t); it is coupled if some xi′x_i'xi′​ depends on some xjx_jxj​ with j≠ij\neq ij=i. An initial value problem prescribes the whole vector x(t0)∈Rn\boldsymbol{x}(t_0)\in\mathbb{R}^nx(t0​)∈Rn.

Interpretation¶

A system describes several interacting quantities, such as two competing populations or prices in linked markets. In the linear case the matrix product AxA\boldsymbol{x}Ax packs all couplings into one coefficient matrix; the entry aija_{ij}aij​ measures how xjx_jxj​ affects the rate of change of xix_ixi​.

The figure shows the coupled example below in the (x1,x2)(x_1,x_2)(x1​,x2​) plane. Along the eigenvector (1,1)⊤(1,1)^{\top}(1,1)⊤ (blue, λ=3\lambda=3λ=3) solutions move outwards like e3t\mathrm{e}^{3t}e3t, along (1,−1)⊤(1,-1)^{\top}(1,−1)⊤ (red, λ=−1\lambda=-1λ=−1) they move inwards like e−t\mathrm{e}^{-t}e−t, and every other solution (grey) combines the two. The green curve is the solution with x(0)=(3,1)⊤\boldsymbol{x}(0)=(3,1)^{\top}x(0)=(3,1)⊤: it comes in near the (1,−1)⊤(1,-1)^{\top}(1,−1)⊤ line and then leaves in the (1,1)⊤(1,1)^{\top}(1,1)⊤ direction. Neither coordinate can be solved on its own, but in eigenvector coordinates the two motions separate.

Every scalar equation of order nnn is a first-order system in disguise: with y1=xy_1=xy1​=x, y2=x′y_2=x'y2​=x′, ..., yn=x(n−1)y_n=x^{(n-1)}yn​=x(n−1) the equation x(n)=f(t,x,…,x(n−1))x^{(n)}=f(t,x,\dots,x^{(n-1)})x(n)=f(t,x,…,x(n−1)) becomes y1′=y2, …, yn−1′=yn, yn′=f(t,y1,…,yn)y_1'=y_2,\ \dots,\ y_{n-1}'=y_n,\ y_n'=f(t,y_1,\dots,y_n)y1′​=y2​, …, yn−1′​=yn​, yn′​=f(t,y1​,…,yn​). For a second-order differential equation this gives a two-dimensional system. So first-order systems are the general framework, and one theory covers all orders.

Coupling is what makes systems harder than nnn separate scalar equations. For constant, diagonalizable AAA the eigenvalues and eigenvectors remove it: a coordinate change along eigenvectors turns the system into decoupled scalar equations. A common error is to solve each row as if the other variables were constants. The discrete-time counterpart is the system of linear difference equations xt+1=Axt\boldsymbol{x}_{t+1}=A\boldsymbol{x}_txt+1​=Axt​.
