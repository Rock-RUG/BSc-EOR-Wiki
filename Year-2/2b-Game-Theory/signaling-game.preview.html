Signalling Game¶

Definition¶

A signalling game is a two-player dynamic Bayesian game with the following timing:

  1. Nature draws the sender's type θ∈Θ\theta\in\Thetaθ∈Θ according to a common prior p(θ)p(\theta)p(θ).
  2. The sender observes θ\thetaθ and chooses a message (signal) m∈Mm\in Mm∈M.
  3. The receiver observes mmm but not θ\thetaθ, and chooses an action a∈Aa\in Aa∈A.

Payoffs are vS(θ,m,a)v_S(\theta,m,a)vS​(θ,m,a) and vR(θ,m,a)v_R(\theta,m,a)vR​(θ,m,a). A sender strategy is a type-contingent message m(θ)m(\theta)m(θ); a receiver strategy is a response a(m)a(m)a(m) to each message; the receiver's beliefs are posteriors μ(θ∣m)\mu(\theta\mid m)μ(θ∣m), one distribution for each message.

Interpretation¶

As an extensive-form game, the receiver has one information set per message, and each contains one node per type. The natural solution concept is therefore perfect Bayesian equilibrium: the receiver needs beliefs after every message, including messages that no type sends.

The figure draws the example below in the usual signalling layout. Nature moves in the centre, the sender knows her type and sends m=0m=0m=0 (left) or m=1m=1m=1 (right), and the receiver observes only mmm: her two nodes after the same mmm form one information set, at which she holds the belief μ(m)=P(H∣m)\mu(m)=\mathbb{P}(H\mid m)μ(m)=P(H∣m) and chooses AAA or RRR. The payoffs at the ends, sender first, show why the message m=1m=1m=1 can separate the types: it costs only 111 for HHH but 333 for LLL.

Different message distributions across types of positive prior probability make the message informative. In a separating equilibrium, each type must weakly prefer its own message to every alternative message, given the receiver's responses; strict preference is not required. In the example below, m=1m=1m=1 is less costly for type HHH, which makes these incentives strict. Equal or zero signalling costs do not by themselves preclude separation: different preferences over the receiver's action can also deter imitation, and indifferent types can choose different messages.

Equilibria are classified by how much the message reveals: in a separating equilibrium each type sends a different message and the receiver learns the type; in a pooling equilibrium all types send the same message and the receiver learns nothing beyond the prior. Other applications include an entrant whose entry decision signals whether it is competitive or weak, and a research institute sending a message to influence a politician's policy choice.

Key Results¶

  • A sender strategy maps types to messages; a receiver strategy maps messages (not types) to actions.
  • On-path beliefs follow from the sender's strategy by Bayes' rule; beliefs after unsent messages are free in a PBE and determine which deviations are deterred.
  • A signalling game typically has several PBEs, both separating and pooling, supported by different off-path beliefs.
  • With at least two types of positive probability, a signalling game has no proper subgames, because each receiver information set spans several types; subgame perfection alone therefore has no bite.
