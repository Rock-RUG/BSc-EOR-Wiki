Second-Price Auction¶

Definition¶

In a second-price sealed-bid auction, each of nnn bidders submits a bid bi≥0b_i\ge0bi​≥0 simultaneously and privately. The highest bidder wins (ties broken at random) and pays the second-highest bid, that is, the highest bid among the other bidders; losers pay nothing. In a private-value auction with valuation θi\theta_iθi​, bidder iii's payoff is θi−max⁡j≠ibj\theta_i-\max_{j\ne i}b_jθi​−maxj=i​bj​ if she wins and 000 otherwise.

Interpretation¶

The winner's own bid decides only whether she wins, not what she pays. Let c=max⁡j≠ibjc=\max_{j\ne i}b_jc=maxj=i​bj​ be the highest rival bid. Winning is worth θi−c\theta_i-cθi​−c, which is positive exactly when c<θic<\theta_ic<θi​. Bidding bi=θib_i=\theta_ibi​=θi​ wins in precisely those cases, so no other bid can do better.

  • Bidding bi>θib_i>\theta_ibi​>θi​ changes the outcome only when θi<c<bi\theta_i<c<b_iθi​<c<bi​: the bidder then wins and pays c>θic>\theta_ic>θi​, a loss.
  • Bidding bi<θib_i<\theta_ibi​<θi​ changes the outcome only when bi<c<θib_i<c<\theta_ibi​<c<θi​: the bidder then loses a profitable win.

Hence truthful bidding is a weakly dominant strategy; it is not strictly dominant, because against many rival bids (for instance ccc far above or far below θi\theta_iθi​) other bids give the same payoff. The argument uses no beliefs about the rivals and no distributional assumptions, but it does rely on private values: with common values, a rival's bid carries information about one's own value.

  • With private values, bi(θi)=θib_i(\theta_i)=\theta_ibi​(θi​)=θi​ is weakly dominant for every type, so the truthful profile is a Bayesian Nash equilibrium for any distribution of values.
  • In the truthful equilibrium the highest-value bidder wins and pays the second-highest valuation.
  • With θi\theta_iθi​ i.i.d. Unif⁡(0,1)\operatorname{Unif}(0,1)Unif(0,1), expected revenue is the expectation of the second-highest order statistic: E[θ(n−1)]=n−1n+1\mathbb{E}[\theta_{(n-1)}]=\frac{n-1}{n+1}E[θ(n−1)​]=n+1n−1​, the same as in the first-price auction.
  • The truthful equilibrium is not the only BNE: for n=2n=2n=2 with values on [0,1][0,1][0,1], "bidder 1 bids 111, bidder 2 bids 000" is also an equilibrium, but it uses weakly dominated strategies and can give the object to the lower-value bidder.
  • The English auction with private values leads to the same outcome as the truthful second-price equilibrium.
