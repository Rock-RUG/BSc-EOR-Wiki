Bayesian Game¶

Interpretation¶

A Bayesian game extends a normal-form game to private information. Without types there would be nothing a player knows that the others do not; with types, each player must think about what every possible type of every opponent would do.

Two misunderstandings are common. First, a strategy is not the action actually taken; it must specify what each type would do, because the others' optimal choices depend on all of them. Second, payoffs may depend on the others' types as well as one's own (interdependent values, as with car quality in the market for lemons); "private values" is the special case vi(a;θi)v_i(a;\theta_i)vi​(a;θi​).

Key Results¶

  • With finite sets, player iii has ∣Ai∣∣Θi∣|A_i|^{|\Theta_i|}∣Ai​∣∣Θi​∣ pure strategies.
  • If every Θi\Theta_iΘi​ is a singleton, the Bayesian game is an ordinary normal-form game of complete information.
  • The equilibrium concept is the Bayesian Nash equilibrium: each type best responds given her beliefs.
  • The game can equivalently be drawn as an extensive-form game in which Nature moves first, the Harsanyi transformation.

The low-cost type's choice depends on what she expects the other to do; this is solved on the Bayesian Nash equilibrium page.

Auctions. In a sealed-bid auction each bidder's type is her valuation, her action is a bid, and payoffs depend on all bids; see the first-price auction.
