Common Prior¶

Definition¶

Interpretation¶

The common prior assumption says that players differ in what they know, not in how they interpret the world: any difference in beliefs comes from different private information. Each type's belief is the conditional probability of the others' types given her own, obtained from ppp by Bayes' rule.

Player 1 of type aaa knows she is in the outlined row and rescales it by its total 0.50.50.5, giving p(x∣a)=0.8p(x\mid a)=0.8p(x∣a)=0.8; player 2 of type xxx knows she is in the dashed column and rescales it by 0.60.60.6, giving p(a∣x)=23p(a\mid x)=\tfrac{2}{3}p(a∣x)=32​. Different types end up with different beliefs only because they condition on different parts of the same ppp.

This is what lets a Bayesian game be written as one game with Nature moving first, the Harsanyi transformation: Nature draws θ\thetaθ from ppp, and everyone knows that it does.

When types are correlated, a player's own type is informative about the others', so different types of the same player hold different beliefs; using the marginal distribution of θ−i\theta_{-i}θ−i​ in that case is a frequent error. Only independent types give every type the same belief (Key Results).

Key Results¶

  • Beliefs consistent with a common prior satisfy p(θi) p(θ−i∣θi)=p(θ)p(\theta_i)\,p(\theta_{-i}\mid\theta_i)=p(\theta)p(θi​)p(θ−i​∣θi​)=p(θ) for all iii and θ\thetaθ.
  • With independent types, p(θ)=∏jpj(θj)p(\theta)=\prod_jp_j(\theta_j)p(θ)=∏j​pj​(θj​) and p(θ−i∣θi)=p(θ−i)p(\theta_{-i}\mid\theta_i)=p(\theta_{-i})p(θ−i​∣θi​)=p(θ−i​) for every type θi\theta_iθi​: all types of player iii hold the same belief, the product of the others' marginals.
  • Not every belief system comes from a common prior: two players without private information who assign different probabilities to the same event cannot share one. More generally (Aumann's agreement theorem), under a common prior, posteriors about an event that are common knowledge must be equal.
  • Under a common prior, a type's expected payoff is computed with p(⋅∣θi)p(\cdot\mid\theta_i)p(⋅∣θi​); the ex ante expected payoff averages these with weights p(θi)p(\theta_i)p(θi​).
