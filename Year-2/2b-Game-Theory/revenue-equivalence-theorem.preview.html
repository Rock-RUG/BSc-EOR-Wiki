Revenue Equivalence Theorem¶

Theorem¶

Suppose that

  1. nnn bidders are risk-neutral;
  2. values are independent private values: θ1,…,θn\theta_1,\dots,\theta_nθ1​,…,θn​ are i.i.d. with a continuous cumulative distribution function (CDF) FFF that has a positive density on [θ‾,θ‾][\underline\theta,\overline\theta][θ​,θ], and each bidder knows only her own value;
  3. two auction formats each have a Bayesian Nash equilibrium in which the object always goes to the bidder with the highest value;
  4. in both equilibria a bidder with the lowest possible value θ‾\underline\thetaθ​ has expected surplus 000.

Then in both equilibria each type θ\thetaθ has the same expected payment

m(θ)=θ G(θ)−∫θ‾θG(x) dx,G(θ)=F(θ)n−1,m(\theta)=\theta\,G(\theta)-\int_{\underline\theta}^{\theta}G(x)\,\mathrm{d}x,\qquad G(\theta)=F(\theta)^{n-1},m(θ)=θG(θ)−∫θ​θ​G(x)dx,G(θ)=F(θ)n−1,

and the seller's expected revenue is the same, namely E[θ(n−1)]\mathbb{E}[\theta_{(n-1)}]E[θ(n−1)​], the expectation of the second-highest value.

Interpretation¶

In equilibrium, a bidder's expected surplus U(θ)=θG(θ)−m(θ)U(\theta)=\theta G(\theta)-m(\theta)U(θ)=θG(θ)−m(θ) is pinned down by two things only: the probability G(θ)G(\theta)G(θ) of winning, which is fixed by the allocation rule (condition 3), and the surplus of the lowest type (condition 4). An envelope argument gives U′(θ)=G(θ)U'(\theta)=G(\theta)U′(θ)=G(θ), so U(θ)=U(θ‾)+∫θ‾θG(x) dxU(\theta)=U(\underline\theta)+\int_{\underline\theta}^\theta G(x)\,\mathrm{d}xU(θ)=U(θ​)+∫θ​θ​G(x)dx. Expected payments, and so expected revenue, then cannot differ across formats.

Both areas depend only on GGG, which the allocation rule fixes, and on the zero surplus of the lowest type, which is why the auction format drops out.

Each hypothesis matters. With risk-averse bidders the first-price auction yields more revenue than the second-price auction. With a reserve price above θ‾\underline\thetaθ​, low types never win, so condition 3 fails and revenue can change. With asymmetric value distributions the first-price equilibrium need not allocate to the highest value. With affiliated or common values the formats can rank differently.

A common misunderstanding is that the formats give the same revenue in every realization. They do not: the theorem is about expected revenue. In a second-price auction the price is the realized second-highest value; in a first-price auction it is the winner's bid, which varies differently.
