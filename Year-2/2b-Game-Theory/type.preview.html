Type¶

Definition¶

In a Bayesian game, a game of incomplete information, player iii's type θi\theta_iθi​ is everything payoff-relevant that iii knows privately and the others do not, such as her cost, valuation, quality or preferences. It is drawn from a type space Θi\Theta_iΘi​ and observed only by iii. A profile of types is θ=(θ1,…,θn)\theta=(\theta_1,\dots,\theta_n)θ=(θ1​,…,θn​), an element of the Cartesian product Θ=Θ1×⋯×Θn\Theta=\Theta_1\times\cdots\times\Theta_nΘ=Θ1​×⋯×Θn​, and payoffs vi(a;θ)v_i(a;\theta)vi​(a;θ) may depend on the whole profile. From the others' point of view, θi\theta_iθi​ is a random variable whose distribution is part of the description of the game.

Interpretation¶

In a normal-form game every player's payoff function is common knowledge. Types relax exactly this: the structure of the game (players, actions, the type spaces and the distribution of types) remains common knowledge, but the realized type of each player is private. Uncertainty about another player's payoffs becomes uncertainty about which type she is.

A type also fixes the player's beliefs. Given a common prior ppp over Θ\ThetaΘ, type θi\theta_iθi​ believes the others' types are distributed as p(θ−i∣θi)p(\theta_{-i}\mid\theta_i)p(θ−i​∣θi​); with independent types this belief does not depend on θi\theta_iθi​.

The key consequence for strategies: because the other players do not see θi\theta_iθi​, they must predict what every type of iii would do. A strategy is therefore a type-contingent plan si ⁣:Θi→Ais_i\colon\Theta_i\to A_isi​:Θi​→Ai​, not a single action, even though only one type is realized. Treating each type as a separate "player" who maximizes her own expected payoff is a useful way to think about this.

Key Results¶

  • With finite Θi\Theta_iΘi​ and AiA_iAi​, player iii has ∣Ai∣∣Θi∣|A_i|^{|\Theta_i|}∣Ai​∣∣Θi​∣ pure strategies.
  • A player with a single possible type (∣Θi​∣=∣Θi∣=1|\Theta_i|=11) has no private information; if all players do, the game reduces to a game of complete information.
  • Types are the moves of Nature in the Harsanyi transformation: Nature draws θ\thetaθ, and each player observes only her own component.
  • A type can encode information about the state of the world (for example, a signal about a common value), not only preferences.

Examples¶

Private costs. Two neighbours decide whether to contribute to a shared good worth 1 to each if at least one contributes. Contributing costs θi∈Θi={14,2}\theta_i\in\Theta_i=\{\tfrac{1}{4},2\}θi​∈Θi​={41​,2}, known only to iii. Quality. A used-car seller's type is the car's quality θ∈{L,H}\theta\in\{L,H\}θ∈{L,H}. The buyer does not observe it and must form beliefs about it; this is the setting of the market for lemons.
