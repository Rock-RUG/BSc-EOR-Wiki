Equilibrium Path¶

Definition¶

In an extensive-form game, a strategy profile σ\sigmaσ, together with Nature's probabilities, determines for every node xxx the probability Pσ(x)\mathbb{P}_\sigma(x)Pσ​(x) that play passes through xxx. The path of play (or outcome) of σ\sigmaσ consists of the nodes and actions reached with positive probability. For a pure-strategy profile without moves of Nature in a finite game it is a single sequence of nodes from the root x0x_0x0​ to one terminal node zzz.

If σ∗\sigma^*σ∗ is an equilibrium, its path of play is the equilibrium path. An information set hhh is on the equilibrium path if it is reached with positive probability,

Pσ∗(h)=∑x∈hPσ∗(x)>0,\mathbb{P}_{\sigma^*}(h)=\sum_{x\in h}\mathbb{P}_{\sigma^*}(x)>0,Pσ∗​(h)=x∈h∑​Pσ∗​(x)>0,

and off the equilibrium path if Pσ∗(h)=0\mathbb{P}_{\sigma^*}(h)=0Pσ∗​(h)=0.

Interpretation¶

The path is what an observer would actually see when the equilibrium is played. A strategy says more: it also prescribes what a player would do at information sets that are never reached. That off-path part describes the threats and promises that keep the other players on the path. In the entry game, the incumbent's plan to fight after entry is never carried out when the entrant stays out, yet it is exactly what keeps the entrant out.

Both panels show the entry game from the Examples, with payoffs (entrant, incumbent). Under the Nash equilibrium (Out, FFF) on the left, the path is the single thick green branch Out; the incumbent's node (open circle) is never reached, and her planned FFF (orange, dashed) is the off-path threat that keeps the entrant out without ever being carried out. Under the SPNE (In, AAA) on the right, the same node is on the path In, AAA. The tree is identical in both panels; only the strategy profile decides which nodes are on the equilibrium path.

Being on or off the path is a property of the profile, not of the tree. The same information set is on the path under one profile and off it under another, and a subgame that is off the path is still a subgame.

Off-path behaviour does not change anyone's payoff under σ∗\sigma^*σ∗, so Nash equilibrium puts no optimality requirement on it. This is why Nash equilibria can rest on threats that the player would never carry out. A subgame-perfect Nash equilibrium closes this gap by requiring a Nash equilibrium in every subgame, including the subgames off the path. In games with perfect information, backward induction finds it by fixing optimal behaviour at every node, reached or not, before the path is known.

Describing an equilibrium only by its path is a common mistake: an equilibrium is a full profile, and two different equilibria can have the same path. Conversely, the question "is this profile subgame perfect?" cannot be answered from the path alone.

Key Results¶

  • Payoffs depend only on the path: two profiles that induce the same probabilities over terminal nodes give every player the same expected payoffs, whatever they prescribe off the path.
  • If a player changes her strategy only at information sets that are off the path of σ\sigmaσ, the path and all payoffs stay the same. Hence the Nash conditions never restrict a player's own off-path actions; these matter only through the incentives of the other players.
  • In a Nash equilibrium, every player acts optimally at each of her information sets on the equilibrium path, given the probabilities with which its nodes are reached; non-credible behaviour can occur only off the path.
  • In a Nash equilibrium, the restriction to a subgame reached with positive probability is automatically a Nash equilibrium of that subgame. So a Nash equilibrium is subgame perfect if and only if its restriction to every subgame off the path is a Nash equilibrium as well.
  • The whole game is a subgame that is always on the path. If a game has no proper subgame, every Nash equilibrium is subgame perfect, whatever it prescribes off the path.

Looking ahead:

  • In a multistage game with observed actions (Week 4), a history ht=(a0,…,at−1)h^t=(a^0,\dots,a^{t-1})ht=(a0,…,at−1) is on the path if σ∗\sigma^*σ∗ generates it with positive probability, and the one-stage deviation principle must be checked at every history, including histories off the equilibrium path.
  • A weak perfect Bayesian equilibrium (Week 7) requires sequential rationality at every information set, given a system of beliefs. Bayes' rule determines the beliefs only on the equilibrium path; off the path they may be any probability distribution over the nodes.
