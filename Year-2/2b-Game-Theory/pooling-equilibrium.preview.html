Pooling Equilibrium¶

Definition¶

In a signalling game, a pooling equilibrium is a perfect Bayesian equilibrium in which every type of the sender chooses the same message m∗m^*m∗. On the path the receiver's belief after m∗m^*m∗ equals the common prior,

μ(θ∣m∗)=p(θ)for every type θ,\mu(\theta\mid m^*)=p(\theta)\qquad\text{for every type } \theta,μ(θ∣m∗)=p(θ)for every type θ,

and the receiver best responds to the prior. Every other message m≠m∗m\ne m^*m=m∗ is off the equilibrium path, and the beliefs μ(⋅∣m)\mu(\cdot\mid m)μ(⋅∣m) there are part of the equilibrium but not restricted by Bayes' rule.

Interpretation¶

In a pooling equilibrium the message carries no information: the receiver learns nothing it did not already know. This can happen even when types differ a lot, as long as no type gains from breaking away.

The LLL payoff never reaches 000, and the HHH payoff stays below it exactly when the receiver rejects m=1m=1m=1, so the shaded beliefs μ′≤12\mu'\le\tfrac{1}{2}μ′≤21​ support the pooling equilibrium, while beliefs above 12\tfrac{1}{2}21​ make HHH break away.

Whether a type gains from deviating depends on how the receiver would interpret the deviation, that is, on the off-path part of the system of beliefs. Pooling equilibria are typically supported by pessimistic off-path beliefs: any deviation is read as coming from the "bad" type, which makes deviation unattractive. Since PBE allows any off-path belief, many pooling equilibria can exist; forward induction, mentioned only briefly in the course, asks whether such beliefs are plausible.

A frequent mistake is to check only the on-path condition. A complete verification has three parts: on-path beliefs equal the prior; the receiver's actions are optimal after the pooled message and after each unused message given the stated beliefs; and no type prefers an unused message.

Key Results¶

  • On the path the posterior equals the prior, because all types send m∗m^*m∗ with probability one.
  • Fix a receiver action after m∗m^*m∗ that is a best response to the prior. Pooling on m∗m^*m∗ with that action is a PBE if and only if some off-path beliefs, with optimal receiver responses to them, make every type weakly prefer m∗m^*m∗ to every other message.
  • When the receiver's response is monotone in the belief, as in the example below, more pessimistic off-path beliefs make pooling easier to sustain; with sufficiently optimistic ones it can break down.
  • Pooling and separating equilibria can coexist and give different payoffs: in the example below type HHH gets 000 when pooling and 2−1=12-1=12−1=1 in the separating equilibrium.
