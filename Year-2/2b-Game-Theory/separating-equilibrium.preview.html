Separating Equilibrium¶

Definition¶

In a signalling game, a separating equilibrium is a perfect Bayesian equilibrium in which different types of the sender choose different messages: m(θ)≠m(θ′)m(\theta)\ne m(\theta')m(θ)=m(θ′) whenever θ≠θ′\theta\ne \theta'θ=θ′. In the finite-type model considered here, on-path messages sent with positive probability reveal the type, so the receiver's beliefs are degenerate:

μ(θ∣m(θ))=1for every type θ with positive prior probability,\mu\big(\theta\mid m(\theta)\big)=1\qquad\text{for every type }\theta\text{ with positive prior probability},μ(θ∣m(θ))=1for every type θ with positive prior probability,

so after every positive-probability message the receiver knows the sender's type and best responds to it. A message prescribed only for a zero-prior type is off the path; its belief is not determined by this Bayes ratio.

Interpretation¶

On the equilibrium path, separation makes the message reveal the private information. The beliefs follow from Bayes' rule: if only a positive-prior type θ\thetaθ sends mmm, the posterior puts probability one on θ\thetaθ.

The binding conditions are the senders' incentive constraints: each type must weakly prefer its own message and the receiver's response to any alternative message and its response. Equal payoffs permit either choice. In general these comparisons depend on type-specific benefits and costs; separation does not require a universal strict ordering of signal costs. In the example below, type HHH must find m=1m=1m=1 cheap enough to be worth being accepted, and type LLL must find it expensive enough not to copy HHH.

Two misconceptions are common. First, a costly signal uses resources: in the example below m=1m=1m=1 produces nothing, and type HHH pays cHc_HcH​ to be identified. This cost alone does not establish Pareto inefficiency within the same game. An efficiency comparison must specify which alternative information or allocation is feasible. Second, when the message space contains messages that no type sends, off-path beliefs still matter, because they determine whether a type would deviate to an unused message.

Key Results¶

  • In a separating PBE every on-path belief is 000 or 111; the receiver plays a complete-information best response to each type.
  • Incentive compatibility: vS(θ,m(θ),a(m(θ)))≥vS(θ,m′,a(m′))v_S\big(\theta,m(\theta),a(m(\theta))\big)\ge v_S\big(\theta,m',a(m')\big)vS​(θ,m(θ),a(m(θ)))≥vS​(θ,m′,a(m′)) for every type θ\thetaθ and every message m′m'm′, including unused ones.
  • With two positive-prior types and two messages, a separating PBE leaves no message off the path, so Bayes' rule pins down both beliefs.
  • Separating and pooling equilibria can coexist in the same game.
