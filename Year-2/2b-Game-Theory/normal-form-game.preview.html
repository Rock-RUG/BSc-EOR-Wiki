Normal-Form Game¶

Definition¶

A normal-form game (strategic-form game) is a triple

G=⟨N, {Si}i∈N, {vi}i∈N⟩,G=\big\langle N,\ \{S_i\}_{i\in N},\ \{v_i\}_{i\in N}\big\rangle,G=⟨N, {Si​}i∈N​, {vi​}i∈N​⟩,

where N={1,…,n}N=\{1,\ldots,n\}N={1,…,n} is a finite set of players, SiS_iSi​ is the nonempty set of pure strategies of player iii, and vi ⁣:S→Rv_i\colon S\to\mathbb{R}vi​:S→R is player iii's payoff function on the set of profiles S=S1×⋯×SnS=S_1\times\cdots\times S_nS=S1​×⋯×Sn​, a Cartesian product.

Payoff matrix. When n=2n=2n=2 and S1S_1S1​, S2S_2S2​ are finite, the game is displayed as a bimatrix: player 1's strategies label the rows, player 2's strategies label the columns, and the cell in row s1s_1s1​ and column s2s_2s2​ contains the pair v1(s1,s2), v2(s1,s2)v_1(s_1,s_2),\,v_2(s_1,s_2)v1​(s1​,s2​),v2​(s1​,s2​). The first number always belongs to the row player.

Interpretation¶

The normal form lists who plays, what each player can do and what each profile pays. It is the natural description of a static game of complete information; dynamic games, written as extensive-form games, can also be converted to normal form (Week 3), but the timing of moves is then no longer visible.

The figure labels the parts of the triple in the Prisoner's Dilemma example: the rows are S1={M,F}S_1=\{M,F\}S1​={M,F}, the columns are S2={M,F}S_2=\{M,F\}S2​={M,F}, and the cell in row s1s_1s1​ and column s2s_2s2​ holds v1(s1,s2)v_1(s_1,s_2)v1​(s1​,s2​) (blue, first) and v2(s1,s2)v_2(s_1,s_2)v2​(s1​,s2​) (red, second); for instance, row FFF, column MMM holds −1,−5-1,-5−1,−5. The arrows show which numbers each player compares: player 1 fixes the column and compares first entries down it (−2-2−2 against −1-1−1 in column MMM), while player 2 fixes the row and compares second entries along it (−5-5−5 against −4-4−4 in row FFF).

To read a matrix correctly: player 1 compares first entries down a column (the column fixes s2s_2s2​), and player 2 compares second entries along a row (the row fixes s1s_1s1​). Comparing the wrong entries is a frequent error when looking for best responses.

For pure-strategy analysis (dominance, best responses, pure Nash equilibrium) only each player's ranking of profiles matters. For mixed strategies (Week 2) the payoff values themselves matter, because players then take expectations.

Key Results¶

  • A finite two-player game with mmm rows and kkk columns is described by 2mk2mk2mk numbers; in general a finite game needs n⋅∣S1∣⋯∣Sn∣n\cdot|S_1|\cdots|S_n|n⋅∣S1​∣⋯∣Sn​∣ numbers.
  • Applying any strictly increasing transformation to one player's payoffs leaves strict dominance between pure strategies, best responses to pure strategies and pure Nash equilibria unchanged; a positive affine transformation αvi+β\alpha v_i+\betaαvi​+β, α>0\alpha>0α>0, also leaves the mixed-strategy analysis unchanged.
  • A two-player game is zero-sum if v1(s)+v2(s)=0v_1(s)+v_2(s)=0v1​(s)+v2​(s)=0 for every profile sss.
  • A two-player game is symmetric if S1=S2S_1=S_2S1​=S2​ and v1(a,b)=v2(b,a)v_1(a,b)=v_2(b,a)v1​(a,b)=v2​(b,a) for all a,ba,ba,b.
  • Strategy sets may be infinite, in which case the game is given by formulas rather than a matrix.
