    About this wiki¶

    This page explains how to find topics quickly, use the revision tools well, keep your own learning record, sync across devices, and send useful improvement requests when a page can be made clearer.

    Everything below is split into short collapsible sections. Open only what you need.

    Quick start¶

    If you want to browse by course¶

    Start from Year 1 and move into the relevant course. This is the best route when you want the material in teaching order.

    If you know the topic already¶

    Use the Search bar at the top of the page. This works well for direct concept names, aliases, course codes, and lecture tags.

    If you want to stay inside one course¶

    Use Search in course on a course page. This keeps the search local to the course you are currently studying.

    If you want a revision set¶

    Use Search & Filter. It lets you combine tokens and build a targeted pool for random revision, self-testing, or exam preparation.

    If you want the wiki to remember your progress¶

    Open the My menu and sign in. Your account can keep mastery ratings, saved pages, learning events, XP, AI quiz history, profile settings, and sync status.

    If you do not know what to study next¶

    Open a concept page and use the Learning Path, the map button, your mastery level, rankings, and the guided study tools. These are designed for situations where the problem is not finding one page, but finding the right next step.

    Account, sync, and personal data¶

    What the account layer does¶

    The wiki has a personal study layer on top of the public concept pages. This layer can remember:

    • mastery ratings
    • saved pages and saved-page visits
    • random revision activity
    • guided study activity
    • AI mastery check history
    • XP and level progress
    • profile information used in rankings and comments
    • connected devices and sync status

    Local file and cloud file¶

    Each device keeps a local account data file in the browser. Each signed-in account has a cloud account data file. When you run sync, the wiki merges the local file and the cloud file, then checks that the final event file is aligned.

    This means the normal direction is not simply “upload” or “download”. A laptop may have some events that the cloud does not have, while the cloud may also contain events from a phone. Sync is meant to merge both sides into one account history.

    When you are not signed in¶

    Some study data can still be stored locally in the browser. However, local-only data does not automatically move to another device. If you clear browser storage or use a different browser profile, local-only data may disappear.

    When you are signed in¶

    Run sync if you want the current device and the cloud account file to match. After sync, another device using the same account can pull the same learning record.

    Connected devices¶

    The account area can show devices that have been used with the account. This is mainly a practical check: it helps you see which device last synced and whether one device has pending learning activity.

    XP, levels, and activity records¶

    What XP means¶

    XP is a study-activity signal. It helps make learning activity visible, but it is not a course grade and it is not a replacement for understanding.

    How XP is earned¶

    The Level & XP panel explains which actions can give XP. Examples include opening the wiki, visiting concept pages, saving pages, visiting saved pages, changing mastery ratings, using guided study, using maps, completing AI mastery checks, searching in a course, using random revision, and using discussion or improvement tools.

    Daily caps and repeat values¶

    Some actions have daily caps. Some repeated actions count at a reduced value. This keeps the XP system useful as a study signal without making repeated clicking too important.

    Why the account event file matters¶

    XP is calculated from recorded learning events. When a learning event is written to the account event file, it can be counted locally, synced to the cloud, and used by other devices after sync. If an action is not recorded as an event, it cannot increase XP.

    Rankings and profile display¶

    If your account appears in active-user rankings, the display can use your profile name, avatar, avatar frame, level, and XP. These are public-facing study signals inside the wiki, not formal course assessment records.

    Search basics¶

    Find a specific lecture¶

    Every concept page can be connected to a lecture tag. The format is:

    course-lectureXX

    Example:

    m1c-lecture02

    This means Math I: Calculus, Lecture 2. Type the tag into the top search bar and press ENTER to get the concept pages introduced in that lecture.

    Find a concept inside one course¶

    On most course pages you can use Search in course. This is useful when:

    • you remember the course but not the exact page title
    • you want to avoid results from other courses
    • the global search gives too many matches

    Search suggestions and spelling support¶

    The search tools are designed to be forgiving. They can use concept titles, aliases, tags, and nearby text, and they can often recover from small spelling mistakes or missing spaces. This is useful when you remember the mathematical idea but not the exact wording used by the page.

    Search history¶

    The header search remembers recent searches in your browser. This makes it faster to return to a concept, lecture tag, or topic you have been revising.

    Search & Filter¶

    Search & Filter is the best tool when you want a custom revision set rather than a single page. It lets you build a logical expression using:

    • tokens such as keywords, course codes, and lecture tags
    • operators such as AND and OR
    • parentheses such as ( and ) to control grouping

    Basic workflow¶

    1. Type a token in the input box.
    2. Click Add token.
    3. Repeat until the pieces you need are in the token pool.
    4. Build or adjust the expression.
    5. Click Run search.

    Tips¶

    • Use AND to narrow the result set.
    • Use OR to broaden it.
    • Use parentheses when the grouping matters.
    • Use quotes for clarity when you enter tags such as "m3a-lecture05".
    • Use Undo and Redo if you are experimenting with an expression.

    Example¶

    If you want topics about limits and infinity from Math I: Calculus and Math III: Analysis, you can build:

    ("m1c" OR "m3a") AND ("limit" AND "infinity")

    After the results appear¶

    You can then:

    • open a specific concept page
    • select pages and click Start random
    • use the result set as a focused exam revision pool
    • switch the random session between Normal, Self-test, and AI-test where available

    Mastery levels¶

    On every concept page you will see a mastery widget under the title. Use it to record how comfortable you feel with the current concept.

    • Mastered = you can use the concept confidently
    • Familiar = mostly fine, but may still need checking
    • Fuzzy = partly understood, needs more work
    • Unknown = not understood yet

    Why mastery matters¶

    Your ratings are used by the revision tools. Concepts that are still unknown or fuzzy receive more attention, while mastered concepts are pushed down or excluded by default.

    Manage mastery¶

    Click Manage mastery () to review, sort, filter, or reset your ratings across the wiki. This is useful before an exam, or when you want to see which parts of the programme still need attention.

    Mastery and sync¶

    When you are signed in and synced, mastery ratings are part of your account learning record. This makes it possible to move your ratings between devices instead of keeping them only in one browser.

    Saved pages and study queues¶

    Save a page for later¶

    Concept pages can be saved into personal study categories such as favourites, study later, or review later. Use this when a page is important, when it blocks another topic, or when you want to return to it before an exam.

    Visit saved pages deliberately¶

    A saved page is most useful when you return to it. The wiki can record visits to saved pages as part of your learning activity, which also helps XP and revision history reflect what you actually studied.

    Sync saved pages¶

    Saved pages are part of the account data file when you are signed in. After sync, another device should be able to see the same saved-page state.

    Random revision modes¶

    Random revision works best after you have built a focused result set with Search & Filter. The random tools use your selected pool and your mastery data to decide what to show next.

    Normal mode¶

    Use Normal mode when you want to move through the selected concepts and read each page normally. This is good for rebuilding context or revising a broad topic area.

    Self-test mode¶

    Use Self-test when you want active recall. The page opens in a folded state so you can try to recall the idea before opening the content. This is useful for definitions, theorem statements, proof outlines, and method steps.

    AI-test mode¶

    Use AI-test when you want the random session to lead into an AI mastery check where one is available. This is useful when you want a quick diagnostic rather than only reading the page.

    Continue, edit, or exit¶

    During a random session you can:

    • click Continue random to move to another concept from the same pool
    • click Switch to ... to change between Normal, AI-test, and Self-test
    • click Edit filter to return to the filter that produced the pool
    • click Exit to stop the random session

    AI mastery checks¶

    Some concept pages include an AI mastery check button. This opens a short multiple-choice concept check for the current page.

    How to use it well¶

    Try the questions before rereading the page. After each answer, use the feedback to identify whether the problem was notation, a definition, a condition, or a method step.

    Suggested mastery level¶

    At the end of the check, the tool may suggest a mastery level. Treat this as feedback, not as a final judgement. You can accept the suggested level or keep your own assessment.

    AI quiz history¶

    AI quiz completion can be recorded as part of your account learning history. When synced, this helps keep the same learning record across devices and supports XP, mastery review, and active-user rankings.

    Best use cases¶

    AI mastery checks are especially useful when:

    • a concept feels familiar but you are not sure you can use it
    • you want a quick diagnostic before exam revision
    • you want to distinguish between “I recognise this” and “I can apply this”

    Learning Path, maps, and guided study¶

    Concept pages are connected through a concept graph. The graph is used by the Learning Path panel, local maps, and guided study routes.

    Learning Path panel¶

    The Learning Path panel helps you move with purpose. It can show:

    • prerequisites, meaning what to learn first
    • dependents, meaning what this concept unlocks next
    • related concepts, meaning nearby ideas that are useful but not strictly prerequisite or dependent
    • mastery information, so you can see whether the next step is likely to be ready, weak, or unknown

    Local concept map¶

    Click the map button near the page title to open a local map around the current concept. Use it when a proof, method, or example breaks down and you need to inspect nearby prerequisite or dependent ideas.

    Guided study¶

    Guided study builds a route through the concept graph. Depending on where you start, it can help you move into a target concept through prerequisites, or move forward from a concept into later dependents.

    When a guided study route is active, you may see a route bar near the page title. Use Continue guided study to move along the route and Finish guided study when the route is complete.

    Map fog and unknown nodes¶

    The map may hide or blur unknown concepts so that the structure is visible without revealing everything at once. This is meant to support exploration and active recall, not to block navigation. You can reveal nodes by interacting with the map.

    Comments, reactions, and edit requests¶

    Comments and reactions¶

    Some pages include lightweight discussion tools. Use them when a concept needs clarification, when a point is useful to other students, or when a page has generated a question that is not only personal.

    Edit requests¶

    If a page contains a mistake, unclear wording, a missing prerequisite, a broken link, or a place where an example would help, send an edit request. A good request is specific: identify the page, the part that should change, and the reason.

    What edit requests are for¶

    Edit requests are not just typo reports. They are a way to improve the knowledge network while studying it. Useful requests include:

    • correcting a definition, condition, formula, or reference
    • suggesting a clearer explanation
    • pointing out a missing prerequisite link
    • suggesting a related concept link
    • proposing an example or warning note
    • reporting a page where the AI check, map, or study route feels mismatched

    Account connection¶

    When you are signed in, some contribution activity can be attached to your account profile and may appear in contribution-related views. This helps the wiki recognise useful maintenance work as part of the community layer.

    Rankings¶

    Rankings shows which concepts and users are attracting activity across the wiki. Depending on the selected view, you can compare concepts by views, popularity, comments, saved pages, or active users. It is not a replacement for your own revision plan, but it can help you see where attention is concentrated across the programme.

    Good uses of Rankings:

    • checking which topics other students are revisiting before a test
    • noticing concepts that are suddenly receiving more attention
    • comparing different ranking views before choosing a revision target
    • combining ranked topics with your own mastery ratings to decide what to study next
    • checking active-user XP as a rough engagement signal, not as a formal academic measure

    Practical study patterns¶

    Before a tutorial, quiz, or weekly test¶

    Search the lecture tag, then revise that subset. This keeps the session small and closely aligned with what you have just learned.

    When you are stuck on one proof step¶

    Open the concept page and check the prerequisites. Often the gap is not in the page itself, but one step behind it.

    When you want active recall¶

    Build a Search & Filter pool, start random revision, and switch to Self-test. Try to recall definitions, assumptions, and method steps before opening the folded sections.

    When you want diagnosis¶

    Use AI mastery check on a concept page, or switch a random session to AI-test. This helps you test whether you can actually use the concept.

    When you want a route¶

    Use the map or guided study tools. This is helpful when you know the target concept but do not know which missing prerequisites are blocking you.

    When you study across devices¶

    Sign in, run sync, and check the account sync area before relying on another device. This is especially useful if you changed mastery ratings, completed AI checks, or saved pages on a different device.

    When you find a mistake¶

    Send an edit request while the context is fresh. A precise correction request is usually more useful than a general comment that something is unclear.

    For broader exam revision¶

    Combine course codes, topic keywords, and lecture tags in Search & Filter, then run a mastery-aware random session. Use Manage mastery to check which concepts still need work.

    Notes and troubleshooting¶

    Math rendering¶

    If a formula appears as raw LaTeX rather than rendered mathematics, refresh the page. The site also includes support for dynamically inserted mathematics in search results, maps, popovers, and learning-path panels.

    Wide formulas on small screens¶

    Long displayed formulas may become horizontally scrollable. This is intentional, because it keeps the formula readable without shrinking the whole page.

    Hover previews¶

    On desktop, hovering over many concept links can show a short preview. On touch devices, the site avoids hover-only behaviour and uses tap-friendly interactions instead.

    Site animations¶

    The header includes a motion control. Use it if you prefer reduced animation, or if your system reduced-motion setting is enabled.

    Sync status¶

    If the account area says that the device and cloud are not aligned, run sync again and check the step indicator. A signed-in account uses a local data file on the device and a cloud data file for the account, so both sides need to be aligned before another device can show the same learning record.

    Browser-local data¶

    Some data can exist locally before you sign in or before you sync. If something looks temporarily inconsistent, refresh the page first. If the issue is about different devices showing different learning records, open the account area and compare the sync status on both devices.

    Choosing the right tool¶

    A simple rule is:

    • Search for one page
    • Search in course for one page inside one course
    • Search & Filter for a custom revision set
    • Random revision for repeated practice
    • Self-test for active recall
    • AI mastery check for quick diagnosis
    • Learning Path / map / guided study for dependencies, missing prerequisites, and routes through the concept graph
    • Account / sync for personal progress across devices
    • Edit request for mistakes, unclear explanations, missing links, and suggested improvements
